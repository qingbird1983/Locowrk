# 架构 03：关键接缝（防返工清单）

- 状态：定稿
- 日期：2026-10-28
- 关联：architecture/01、02、04、05；standards/05

> “接缝”指后面一定要扩展、但现在不能写死的地方。每条接缝给出**约束**与**检查点**；检查点必须可执行（测试、编译期断言或脚本），不能只是口号。

## 接缝 #1：事件契约与会话隔离

**约束**：所有 UI、插件、日志只消费 `eventbus.Event`；不得读取 `agent.Agent` 的内部状态。事件带 `SessionID` 与每会话 `Seq`，可多会话并行。

**检查点**：`eventbus` 的契约测试断言 10 类生命周期事件与上游常量一一映射；两个会话并发运行时事件不串流；`Seq` 单调。

## 接缝 #2：与 UI 框架无关的宿主门面

**约束**：`HarnessService` 的入参/出参只能是项目 DTO（JSON 可序列化），不得出现 `mygo`、`ui`、`*ui.Context` 等类型。桌面壳只是它的一个消费者，未来可换 Web 壳/CLI。

**检查点**：`go list -deps ./internal/bridge` 不含 `egoist/mygo`；`go doc` 导出的公开符号中无 UI 包类型（人工核对 + review checklist）。

## 接缝 #3：取消贯穿

**约束**：每个用户动作（发消息、跑工具、加载插件、子进程调用）都带 `context.Context`；取消必须能到达模型请求、工具执行与插件子进程。取消不是错误。

**检查点**：测试在 2 秒内取消一次流式请求、一次 bash 工具、一次插件 RPC，三者都返回 `context.Canceled` 且无 goroutine 泄漏（`goleak` 或 `runtime.NumGoroutine` 基线）。

## 接缝 #4：会话单写者

**约束**：只有 `coding.SessionRecorder` 写会话文件；桌面、插件、适配器都不得直接 append。压缩、分支、恢复全部走上游 API。

**检查点**：代码审查禁止 `internal/` 之外出现 `.jsonl` 写入；集成测试用 `coding.StartSession` / `LoadSessionTree` 往返一次，消息与工具结果语义不变。

## 接缝 #5：工具执行前审阅

**约束**：危险工具执行前必须经过 `BeforeToolCall`；拒绝 = 不写文件、不 spawn、不改会话。审阅结果可记录，但不得在拒绝后补写“已执行”。

**检查点**：为 `write`/`edit`/`bash`/`powershell` 各写一条拒绝测试，断言文件系统与进程表无变化；会话中只出现拒绝原因。

## 接缝 #6：插件兼容降级

**约束**：安全能力（文件写删、执行、网络）按 manifest 默认拒绝；兼容能力按三分类矩阵处理——支持项真实实现，缓做项返回“未实现”，TUI 项 no-op。任何兼容降级都不得 throw；未声明安全能力 = 拒绝。

**检查点**：mock 调用 `ctx.ui.setWidget` 返回零值、扩展继续执行、诊断只记一次；`notify` 映射到宿主通知；未声明的文件写能力被安全拒绝，且与兼容诊断分开记录。

## 接缝 #7：插件视图生命周期

**约束**：插件只持有**数据状态**；`ui.View` 在主线程每帧构建；`ui.Element` 不得存入插件状态、全局变量或后台 goroutine；WebView 在视图外创建一次，视图只负责展示。

**检查点**：Phase 4 用 MyGo 的无窗口测试器跑多帧，断言插件状态里没有 Element 类型（编译期/反射辅助）；切换页面后 WebView 状态保持。

## 接缝 #8：子进程生命周期

**约束**：插件进程由 `exec.CommandContext` 启动；有启动超时、心跳、请求超时、崩溃重启上限与退出清理。子进程崩溃不得导致宿主退出。

**检查点**：注入“启动即崩溃”“运行中崩溃”“RPC 超时”三种故障，宿主记录诊断、按策略重启或禁用插件，UI 仍可操作。

## 接缝 #9：插件 UI 描述协议

**约束**：子进程返回 UI 时只传声明式描述（JSON），不传可执行代码；描述 schema 版本化，宿主对未知组件降级为占位块。

**检查点**：schema 的 fixture 覆盖未知组件、超深嵌套、超大文本；宿主渲染不 panic、不阻塞主线程超过预算。

## 接缝 #10：凭证与脱敏

**约束**：凭证只进系统钥匙串；配置文件只存引用；日志、事件、诊断、插件协议一律脱敏（key/token/Authorization 头）。插件拿不到未脱敏凭证。

**检查点**：安全测试注入伪 key，断言事件流、日志、插件 RPC 三处都不出现原文；钥匙串不可用时 fail-closed，不回退明文。

## 接缝 #11：项目资源信任门控

**约束**：`<cwd>/.pi/skills` 默认不加载；需要用户显式授权（对应上游 `TrustProject`）。授权状态可见、可撤销。

**检查点**：未授权时技能清单为空且系统提示词不含项目技能；授权后清单出现；撤销后立即消失，且不残留缓存。

## 接缝 #12：内核版本与 API 形状

**约束**：上游类型只在 `internal/kernel` 出现；升级内核不得要求 UI/插件改协议。事件 DTO 与插件协议各自有版本号。

**检查点**：升级演练：只改 `internal/kernel` 与 go.mod，`desktop/`、`proto/` 编译不变；协议 fixture 仍通过。
