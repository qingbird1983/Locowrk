# Phase 7：子进程桌面插件（探索性）

- 状态：草稿
- 日期：2026-10-28
- 关联：ADR-0004；architecture/03、04

## 1. 目标

验证第三方桌面插件通路：独立进程 + manifest + 声明式 UI 描述 → 宿主渲染；插件崩溃不拖垮宿主。

## 2. 开工前置条件

- Phase 4 的插槽与 `DesktopPlugin` 接口稳定。
- Phase 2 的子进程生命周期实现可复用。
- UI 描述 schema v1 定稿（组件白名单、布局、事件、版本协商）。

## 3. 做什么

### 3.1 Manifest

```json
{
  "name": "example-panel",
  "version": "0.1.0",
  "protocol": 1,
  "entrypoint": "plugin.exe",
  "capabilities": ["ui.descriptor", "events.session"],
  "slots": ["session.sidebar"],
  "limits": { "memoryMiB": 256, "rpcTimeoutMs": 30000 }
}
```

- 校验：必填字段、协议版本、能力白名单、slot 存在。
- 本地开发目录 + 显式信任；不做市场与签名（backlog）。

### 3.2 UI 描述

- 组件白名单：容器（row/column/grid）、文本、按钮、列表、分隔线、图片、输入框（只读首版）。
- 事件：点击、提交、滚动位置；宿主 → 插件带 `requestId`。
- 未知组件降级为占位块；超深嵌套/超大文本被拒绝并诊断。
- schema 版本化；不兼容时拒绝加载。

### 3.3 生命周期

- 启动/握手/心跳/超时/重启/禁用；进程树清理。
- 插件只能通过宿主 API 读会话摘要，不能直接读文件。

## 4. 不做什么

- 不做插件市场、签名分发、自动更新。
- 不做“插件自有窗口”模式（backlog）。
- 不允许插件执行任意宿主命令或直接操作窗口/菜单。

## 5. 验收场景

1. **挂载**：示例插件在 `session.sidebar` 显示一个面板，内容来自插件进程。
2. **交互**：点击按钮 → 插件收到事件 → 返回新描述 → 面板更新（往返 <100ms 本机）。
3. **崩溃隔离**：kill 插件进程，宿主不退出，面板显示“插件已停止”，可重启。
4. **启动失败**：manifest 非法/入口不存在/握手超时，诊断明确，不影响其他插件。
5. **资源限制**：插件输出超量/内存超限被终止，记录原因。
6. **协议健壮性**：未知组件、超深嵌套、超大文本、错误 JSON 都不导致宿主 panic。
7. **清理**：禁用/退出后无残留进程与管道。

## 6. 交付物

- manifest schema 与 UI 描述 schema（`proto/`）。
- 示例插件（独立仓库或 `examples/`）。
- 故障注入测试与安全评审记录。
- Phase 7 报告：可行性结论、是否进入正式插件生态。

## 7. 风险

- UI 描述表达力不足：首版只做“信息面板”，复杂界面走原生插件。
- 子进程安全边界：能力声明 + 路径白名单 + 审计；不把“进程隔离”当成完整沙箱。
- 插件生态早产：本阶段只证明通路，不承诺 API 稳定；正式化前写 ADR。
