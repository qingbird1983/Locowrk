# Phase 5：WebView 混合渲染与 Diff 审阅

- 状态：草稿
- 日期：2026-10-28
- 关联：ADR-0002；architecture/03、04

## 1. 目标

在原生窗口内嵌系统 WebView，实现 Diff 审阅插件：Go 侧取 `git diff`，前端高亮渲染；与原生控件并列，切换 tab 不丢状态。

## 2. 开工前置条件

- Phase 4 完成（插槽与宿主稳定）。
- WebView 混合 spike 通过：层级、焦点、弹层、缩放、高 DPI。
- 前端工具链与生成 TypeScript 客户端的构建流程定稿。

## 3. 做什么

### 3.1 基础设施

- `desktop/webview`：WebView 生命周期封装（创建一次、显隐、销毁）。
- 资源服务：本地静态资源用 MyGo 的文件服务/自定义协议；禁止远程加载。
- Typed IPC：Diff 数据、主题、滚动定位；事件推送用 channel。

### 3.2 Diff 插件

- Go 侧：`git diff --no-color`（只读，不经 shell 拼接）；处理大文件截断。
- 前端：并排/统一视图切换、语法高亮、行号、折叠、复制路径。
- 交互：从工具卡片“查看变更”打开 tab；关闭 tab 释放资源。
- 主题：跟随宿主明暗；不引入第二套设计语言。

### 3.3 覆盖层与焦点

- 菜单/对话框/tooltip 由宿主覆盖层统一管理，可覆盖在网页之上。
- WebView 内不实现会与宿主冲突的模态；快捷键由宿主分发。

## 4. 不做什么

- 不做完整代码编辑器、不做三方 Diff 服务、不做远程仓库浏览。
- 不在 WebView 里跑任意用户脚本。

## 5. 验收场景

1. **并排审阅**：修改一个文件后，从工具卡片打开 Diff，左右对比正确，高亮与行号正确。
2. **大 Diff**：10,000 行 diff 在 1 秒内打开，滚动可用；超限显示截断提示。
3. **状态保持**：切到其他 tab 再回来，滚动位置与视图模式保持。
4. **混合层级**：WebView 上的下拉菜单/对话框由宿主覆盖层显示，位置正确，焦点可回到网页。
5. **生命周期**：WebView 只创建一次；关闭 tab 后无残留进程/内存增长。
6. **平台**：Windows 必测；macOS/Linux 至少构建通过并记录差异。
7. **安全**：只加载本地资源；外部链接交系统浏览器；路径与内容不注入 HTML。

## 6. 交付物

- WebView 封装与 Diff 插件。
- 前端构建脚本与 CI 产物校验（不把 `node_modules` 入库）。
- 平台冒烟记录与性能读数。
- Phase 5 报告。

## 7. 风险

- WebView 焦点陷阱：所有弹层走宿主；写测试覆盖“打开/关闭后焦点回到原处”。
- 大 Diff 内存：分块加载/虚拟滚动；Go 侧先截断。
- 前端资产体积：构建产物纳入体量预算；不提交依赖目录。
