# Phase 5：WebView 混合渲染与 Diff 审阅

- 状态：定稿
- 日期：2026-10-28
- 关联：ADR-0002、ADR-0013、ADR-0014；architecture/03、04；[webview 设计](../design/phase-5/webview.md)、[diff 设计](../design/phase-5/diff.md)

## 1. 目标

主区域启用宿主托管的标签页：保留“会话”，新增 Diff 标签页。每个标签页是一张系统 WebView 页面；Go 侧只读取 `git diff`，前端渲染并排/统一视图、行号、折叠与轻量语法着色。切换标签页不丢状态，宿主弹层可覆盖网页，关闭标签页即释放资源。

## 2. 开工前置条件

- Phase 4 完成，插件宿主、原生外框与内嵌主页面稳定（tag `phase-4.end`）。
- 本阶段设计定稿：`design/phase-5/webview.md`、`design/phase-5/diff.md`；语义变更由 ADR-0014 记录。
- **双 WebView 小验证通过**：同窗创建两张、切换显隐、页面状态保留、`ui.Popover` 覆盖、`Destroy` 后无残留。结果写入 `research/03` §11；不通过则先改 ADR 与设计，不进入功能实现。

## 3. 做什么

### 3.1 标签页宿主（`desktop/tabs.go`）

- `TabHost` 接口：打开（按 Key 去重）、激活、关闭、列举；最多 4 个 Diff 标签。
- 每个标签一张 WebView，第一次打开时创建，关闭时 `Destroy`；切换只摆放活动页，隐藏页保留状态。
- 原生标签栏：标题（24 字符截断）、活动下划线、`×`、`⋯` 菜单（刷新/复制路径/关闭）。
- 会话切换与窗口关闭清理全部标签页；标签页不写设置文件。
- 禁止在 `Build` 中创建/销毁 WebView；持锁时也不创建/销毁（主线程死锁）。

### 3.2 Diff 服务（`desktop/diff*.go`）

- 固定参数、无 shell、只读：`git diff --no-color --no-ext-diff --no-textconv --unified=3 -- .`（限定工作区）；`GIT_OPTIONAL_LOCKS=0`；5 秒超时，8 MiB / 20,000 行 / 200 文件上限，DTO 文本预算 4 MiB。
- Go 解析统一 diff 为结构化 DTO：文件、hunk、行号、增删、重命名、二进制、模式变化、截断与解析跳过。
- 隐藏敏感路径（`.env*`、`.ssh/`、私钥、`.git/`、`*.pem`、`*.key`）；只显示已跟踪文件的未暂存改动。
- 绑定：`Desktop.OpenDiff(sessionID, toolCallID)`、`Diff.Load(tabID)`、`Diff.CopyPath(tabID, path)`。
- 工具检查器记录工具参数里的路径，用于打开后定位文件。

### 3.3 Diff 页面（`web/diff.html`、`web/src/diff/*`）

- 顶栏：工作区、HEAD 短哈希、文件数与增删统计、并排/统一、刷新；关闭只在原生标签栏。
- 文件头：状态、路径、增删、复制路径、折叠；hunk 可折叠。
- 固定行高虚拟列表，只挂载视口上下各约 40 行；统一与并排共用行模型。
- 轻量 token 着色（Go/TS/JS/JSON/CSS/HTML/Shell/Python/Rust），未知扩展名纯文本；全部 `textContent`。
- 模式与滚动由页面保持；`diff-reload` 时按首个可见行恢复。
- 空状态、非仓库、无 git、超时、截断、隐藏文件、跳过文件各有明确文案与重试。

### 3.4 页面与宿主接线

- 主页面工具卡片增加“查看变更”（工具结束后显示），调用 `Desktop.OpenDiff`；失败在卡片内提示。
- 生成式客户端重跑；`git diff` 只出现预期方法/DTO。
- 导航护栏：只允许应用来源；`http(s)` 外链交系统浏览器；`window.open` 拒绝。
- 冒烟增加 `diff` 场景；Phase 3/4 的 7 个场景全部回归。

## 4. 不做什么

- 不做代码编辑器、暂存/提交、逐文件历史、blame、搜索、三方合并、远程仓库浏览。
- 不做文件监听与实时刷新；刷新是手动操作。
- 不做未跟踪文件、已暂存改动、跨仓库 diff。
- 不做标签页持久化、拖拽排序、分屏、标签分组。
- 不在 WebView 内实现宿主模态或全局快捷键；不做完整无障碍/视觉打磨（留到 UI 重设计）。
- 不引入成熟语法高亮库；若轻量着色不可接受，先评估依赖准入再改设计。

## 5. 验收场景

1. **并排审阅**：修改一个文件后，从工具卡片“查看变更”打开 Diff，左右对比正确，行号与增删底色正确，语法着色可用。
2. **大 Diff**：10,000 行 diff 在 1 秒内打开，滚动可用；超限显示截断提示；内存不随滚动增长。
3. **状态保持**：切到其他标签页再回来，滚动位置与并排/统一模式保持；重复打开同一文件只激活旧标签并刷新数据。
4. **混合层级**：标签栏 `⋯` 菜单显示在网页之上，位置正确；关闭菜单后焦点回按钮，再 Tab 可进入网页。
5. **生命周期**：每个标签只创建一张 WebView；关闭标签后页面与资源销毁，重复开关无残留；会话切换关闭全部 Diff 标签。
6. **平台**：Windows 必测；macOS/Linux 至少构建通过并记录差异。
7. **安全**：只加载本地资源；外部链接交系统浏览器；路径与 diff 内容不注入 HTML；敏感路径不显示内容；git 命令只读、无 shell、有超时与输出上限。

## 7. 风险

- **双 WebView 行为**：源码支持同窗多 WebView 与隐藏保留页面，但焦点、DPI、销毁回收未实测；spike 是硬前置。失败则退回单 WebView + 路由，需先改 ADR-0014。
- **内存**：每个标签一张 WebView；4 个上限与关闭即销毁。若单页常驻过高，评估非活动标签销毁（会丢页面状态）。
- **大 Diff**：解析、JSON、DOM 三段都可能超预算；用上限、虚拟列表与读数控制，不以“机器快”掩盖。
- **文本选择**：虚拟列表只能选中已挂载行；跨屏复制不承诺。
- **焦点与输入法**：切换标签后键盘进入页面、中文输入需人工确认。
- **隐藏窗口**：`-smoke` 不构建原生内容（P-008）；标签栏渲染靠无窗口 tester 与可见窗口人工。
- **视觉**：标签栏是功能粗稿，尺寸/配色/图标留到 UI 重设计，不在本阶段返工。
