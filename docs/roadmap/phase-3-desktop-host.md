# Phase 3：MyGo 最小宿主

- 状态：定稿（2026-10-28；主壳路径见 ADR-0011）
- 日期：2026-10-28
- 关联：ADR-0002、ADR-0011；architecture/01、02、03；research/03

## 1. 目标

让桌面窗口实时显示 Agent 输出：会话列表、消息流、输入框、取消、设置入口；用 Typed IPC 把 `HarnessService` 暴露给前端；空闲时 CPU 接近 0。

本阶段先做**主壳**，不做插件插槽。

## 2. 开工前置条件

- Phase 1 完成；Phase 2 可并行，但主壳不依赖它。
- MyGo 技术 spike 通过（research/03 §6）：最小闭环已验证（隐藏窗口、WebView2、Typed IPC 双向、纯 Go 构建）；长列表、中文输入、钥匙串、打包在 Phase 3 内逐项验证。
- **主壳渲染路径已定稿**：WebView（ADR-0011）。

## 3. 做什么

### 3.1 进程与门面

- `cmd/locowrk`：装配 kernel + bridge + MyGo。
- `internal/bridge`：`HarnessService`，只收发 DTO：
  - `ListSessions`、`CreateSession`、`Prompt`、`Cancel`、`History`、`SubscribeEvents`、`SetModel`、`SetThinkingLevel`
- Typed IPC：Go 服务绑定；事件用 channel 推送；生成 TypeScript 客户端（WebView 路径）或直接在原生视图中消费（原生路径）。
- `HarnessService` 不出现 MyGo 类型（接缝 #2）。

### 3.2 界面（最小可用）

- 左侧会话列表（新建、切换、最近）。
- 中间消息流：用户/助手/工具卡片；流式文本；代码块等宽；自动滚动可暂停。
- 输入区：多行、发送、停止；发送后清空；错误可见。
- 顶部：模型与思考档选择（读取可用模型列表）。
- 设置：数据目录、凭证状态（只显示“已配置/未配置”，不显示明文）。

### 3.3 性能与生命周期

- 增量事件合并；虚拟化长列表；空闲不轮询。
- 窗口关闭：取消进行中的请求；会话已落盘；插件（后续）先停。

## 4. 不做什么

- 不做插件插槽/原生插件（Phase 4）。
- 不做 Diff 审阅（Phase 5）。
- 不做主题编辑器、多窗口、会话搜索。

## 5. 验收场景

1. **真实会话**：配置一个真实 provider（key 走环境变量或钥匙串），发一条消息，窗口逐字显示回答。
2. **工具过程**：模型调用 `read`/`bash`，工具卡片显示开始、参数、结果/错误与耗时。
3. **取消**：点“停止”，2 秒内停止输出；会话保留已产生内容；可以继续发下一条。
4. **恢复**：重启应用，最近会话在列表中；打开后消息与工具结果与关闭前一致。
5. **空闲**：窗口静置 60 秒，CPU 接近 0%，无持续网络请求。
6. **性能**：加载 5,000 条消息的会话，滚动流畅；流式输出不卡输入框。
7. **边界**：`internal/bridge` 无 MyGo 类型；`internal/kernel` 无 UI 依赖；`go test -race` 全绿。
8. **安全**：界面上任何位置都不显示完整 API key；日志脱敏。

## 6. 交付物

- 可运行的桌面应用（Windows 优先）。
- `HarnessService` 契约测试与前端类型生成产物。
- Phase 3 报告：spike 结论、平台冒烟记录、性能读数、主壳路径决策。

## 7. 风险

- 原生主壳若不达标：切 WebView，不阻塞后续；插件原生路径不受影响。
- WebView 焦点/层级问题：覆盖层统一由宿主管理，插件不得自建模态。
- 事件频率过高：合并 + 虚拟化；必要时降级为“按帧刷新”。
- 模型/凭证配置复杂：设置页只做最小面，复杂供应商配置留后续。
