# ADR-0007：MIT 许可证、项目名与 Windows 优先

- 状态：定稿（许可证与名称待所有者最终确认）
- 日期：2026-10-28
- 关联：README.md；standards/01、06

## 背景

仓库需要许可证、对外名称与平台优先级。依赖链的许可证：pi 为 MIT，`sky-valley/pi` 为 MIT，MyGo 为 MIT；参考项目 PI-Desktop 为 LGPL-3.0、pi-flash 为 GPL-3.0（仅可读思路，不复制代码）。

## 决策

- **许可证**：MIT。
- **项目名**：`pi-go-desktop`（仓库名与可执行文件名同源；正式产品名待所有者确认）。
- **平台优先级**：Windows 优先；macOS/Linux 保证可构建，逐步补齐验收。
- **版权行**：本项目贡献者 + 上游 MIT 版权声明（见 LICENSE）。

## 理由

- 与依赖链一致，分发与再许可最简单；避免 MIT 代码与 GPL 代码混用的解释成本。
- 桌面端用户以 Windows 为主（参考仓库同样选择 Windows 优先）；MyGo 支持三平台。
- 名称直白表达“pi + Go + 桌面”，便于检索。

## 备选（否决）

- **Apache-2.0**：专利条款更明确，但与上游 MIT 生态的兼容说明成本更高，收益不明显。
- **GPL-3.0**：与“可被广泛集成”的目标冲突，且会限制插件生态。
- **暂不设许可证**：默认版权保留，别人无法合法使用；不利于开源协作。

## 后果

- 第三方插件可以自选许可证，但分发时必须保留本项目与上游的版权声明。
- 不得把 LGPL/GPL 参考项目的代码或文档文字搬入本仓库；思路借鉴要在文档中注明来源。
- 产品正式名称变更时，需同步 README、`cmd/` 目录名、安装包名与 CHANGELOG；不另写 ADR（属命名调整），但要在所有者确认后一次改完。
