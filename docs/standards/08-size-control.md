# 规范 08：体量与防膨胀管理

- 状态：定稿
- 日期：2026-10-28
- 关联：.agents/README.md；standards/01/03/04/07

## 0. 目的

一切“只增不减”的集合——文档、AI 知识库、代码、依赖、前端资产——都会无限膨胀。膨胀不是风格问题，而是维护性风险：淹没关键信息、拖慢检索、放大 AI 上下文成本。本规范给每一类集合定**预算 + 清理机制 + 豁免流程**。

## 1. 总原则

1. **单一事实**：任何知识只在一处权威定义，其余位置一律引用；发现重复以“合并 + 引用”处置。
2. **流水账唯一**：全仓库唯一允许的追加式日志是 `CHANGELOG.md`。`docs/` 其余全部是活性文档（覆盖式修订）；会话与过程笔记进 `.agents/`。
3. **预算是硬数字**：超标必须在当轮/当阶段处置（拆分、精炼、合并、删除），或在进度报告登记豁免及理由。
4. **收尾强制核对**：每阶段进度报告含“体量核对”一节（standards/03 附录）。

## 2. 文档预算（docs/ 与根入口文件）

**入口文件定位约束**：

- 根 `README.md`（英）/ `README.zh-CN.md`（中）：只做项目说明与导航，禁止放进度看板、状态、流水账。
- 根 `AGENTS.md`：薄索引（导航 + 铁律链接）；禁止记录状态/进度/阶段指针。
- 新增根入口文件须先修订 standards/01。

| 对象 | 上限 | 超限处置 |
|---|---|---|
| 正式文档单篇（research/architecture/roadmap/standards/design） | ≤300 行 | 拆分（登记 docs/README 新条目）或精炼 |
| 单篇 ADR | ≤100 行 | 一篇只装一个决策，拆篇 |
| 单篇 phase 设计稿 | ≤500 行 | 按模块拆到 `design/phase-N/` 多文件 |
| docs/ 文档总数（`.md` 计，图片不计） | 软上限 120 篇 | 触发整合评审（合并碎片、归并过时篇） |
| 每阶段新增设计稿 | ≤12 篇 | 超出说明阶段切分过细，重新归并（Phase 0 基线文档不计） |

- **过时机制**：被新结论取代的文档，顶部加“已取代：见 XXX”并冻结；连续两个阶段无引用的过时篇可删除（git 历史留存）。
- **孤儿清零**：每阶段核对 `docs/README.md` 与实际文件一致；门禁会自动检查。
- `research/` 结论冻结：新调查新开篇，不改旧篇结论。

## 3. AI 知识库预算（.agents/）

预算与清理机制以 `.agents/README.md §3` 为准（CONTEXT ≤150 行、handoff 滚动 5 份、单篇沉淀 80/120 行、全目录 ≤40 文件且不含 vendored 技能子目录、教训当轮提取）。修改该预算必须修订本规范。

## 4. 代码预算（Phase 1 起生效）

| 对象 | 上限 | 说明 |
|---|---|---|
| 单源文件 | ≤500 行 | 超过必须拆分；测试文件可放宽到 800 |
| 单函数 | ≤60 行 | 指导值；配合 review |
| 单包 | >15,000 行触发拆分评审 | 只在阶段边界做，避免中途动荡 |
| 死代码 | 零容忍 | 无主 `//nolint` / 未使用代码必须删除 |
| 重复代码 | 阶段 review 处置 | 明显复制粘贴 ≥3 处必须抽公共实现 |
| 直接依赖数（每包） | 软上限 15 | 超出在依赖准入表说明 |

- **豁免流程**：确需超标（协议大表、生成代码、数据文件），注释声明原因 + 进度报告登记；**生成代码不计入预算**。
- Phase 1 起提供 `scripts/check-size.sh`/Go 工具（文件行数、豁免清单核对）；先 warn 后视情况升 hard。

## 5. 依赖与前端资产预算

按 standards/04 §5 准入流程执行；补充：

1. 升级窗口化：内核与 MyGo 每阶段最多升级一次，独立提交，便于回滚。
2. “为了一个小功能引入一个大依赖”视为超标；准入表必须记录备选对比。
3. WebView 前端：`node_modules/` 不入库；构建产物（JS/CSS/字体）计入仓库体量，单文件 >1MB 或合计 >10MB 须 ADR 说明。
4. 图片/图标优先 SVG；位图资产单文件 >500KB 须说明来源与用途。

## 6. 构建产物与本地环境

- Go 构建缓存不在仓库内，但本机磁盘会膨胀：阶段收尾可运行 `go clean -cache`（会拖慢下次构建，非必需）。
- 仓库禁止提交二进制、安装包、`dist/`、覆盖率与日志（`.gitignore` 已覆盖）。
- 发布产物放 CI artifact 或 releases，不进 git。
- 测试临时数据用 `t.TempDir()`；不在仓库留“调试用”目录。

## 7. 核对与豁免登记（进度报告附录格式）

```markdown
## 体量核对（standards/08）
- docs/：新增 N 篇 / 总数 X 篇（软上限 120）；超限篇目：
- .agents/：文件数 X（上限 40）；CONTEXT 行数：
- 代码：新增 >500 行文件：无 / 有（附豁免）；最大包行数：
- 依赖：新增 X 个（准入表已更新：是/否）
- 前端资产：新增 X MB；单文件最大：
- 豁免登记：
```

- 同一规则在一个阶段内被豁免 ≥2 次 → 触发 standards/09 复查（处置对象是规则本身）。
