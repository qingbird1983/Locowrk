# 提示词：实现"思考语言"配置

## 任务

在 Locowrk 里加一个配置项，控制 LLM 用什么语言"思考"（即 reasoning 过程用什么语言）。

## 背景

当前 system prompt 里没有关于思考语言的说明，模型默认可能用英文思考。
用户希望模型思考时用中文，但不想硬编码——因为不是所有用户都需要。

## 设计要求

### 1. 不做插件，做设置项

这是一个配置项，不是能力扩展。不要做成中间件插件，不要跨 ABI。
就在设置里加一行下拉框，在会话组装 system prompt 时注入一段提示词。

### 2. 位置：设置 → 模型配置

```
设置 → 模型配置

主模型
  [DeepSeek V4 ▾]

会话记录员
  [同主模型 ▾]

思考语言
  [跟随界面 ▾]
  ├─ 跟随界面（默认）
  ├─ 中文
  ├─ English
  └─ 不指定
```

### 3. 默认值："跟随界面"

- 界面语言是中文 → 思考语言也是中文
- 界面语言是英文 → 思考语言也是英文
- 用户不需要配置就能得到合理结果

### 4. 提示词模板 i18n 化

在 `prompts/` 目录下建立：

```
prompts/
└── thinking_language/
    ├── zh-CN.md     ← "思考过程中请使用中文。"
    ├── en-US.md     ← "Think in English."
    └── none.md      ← 空文件，不注入任何内容
```

主提示词里留一个占位符：

```
# 输出

- 代码用 markdown 代码块
- 回复用 {{reply_language}}

{{thinking_language_hint}}
```

运行时根据配置填充 `{{thinking_language_hint}}`。

### 5. 关键：会话内稳定（前缀缓存红线）

**这是最重要的约束。**

- 会话开始时：读取配置，拼一次 system prompt，**之后就锁死**
- 会话进行中：不管用户怎么改设置，**当前会话不变**
- 新会话开始时：用新配置

如果用户中途改了"思考语言"，UI 上提示："下个会话生效。"
不要中途变——一变，前缀缓存全废。

### 6. 位置：system prompt 的末尾

思考语言 hint 放在 system prompt 的**最末尾**，紧跟在固定内容之后、会话历史之前。

理由：
- 对所有会话是同一个位置
- 是 system prompt 的最后一块
- 跟着会话走，不跟着轮次走
- 位置固定、内容会话内不变 → 缓存安全

### 7. 落盘位置

配置写入 `~/.locowrk/config/llm.toml`：

```toml
[thinking]
language = "follow_ui"  # follow_ui | zh-CN | en-US | none
```

### 8. 用户中途改设置的交互

用户在会话进行中修改思考语言设置：
- 保存到配置文件
- 当前会话不变
- UI 提示："已保存。新设置将在下个会话生效。"

## 验收标准

- [ ] 设置里有"思考语言"下拉框，默认"跟随界面"
- [ ] 界面中文时，模型用中文思考
- [ ] 界面英文时，模型用英文思考
- [ ] 用户可手动指定中文/英文/不指定
- [ ] 会话内 system prompt 逐字节稳定，不破坏前缀缓存
- [ ] 中途修改设置不影响当前会话
- [ ] 新会话使用新配置
- [ ] 提示词从 `prompts/thinking_language/` 读取，不硬编码

## 不要做的事

- 不要做成插件
- 不要每轮动态拼 system prompt
- 不要中途改变当前会话的 system prompt
- 不要在思考语言之外顺手加别的配置
