## 一、目的

功能越多 UI 越乱的根因是**缺落位规则**：新功能来了不知道该放哪个按钮、哪个面板、
点了往哪流。本文件把规则定死，后续批次照表扩容：

1. 新功能 = 新数据流（store）+ 模式组件的实例化 + §四流向图加一行；
2. 不改壳骨架（§二）、不发明新交互形态（§三）；
3. 想放的东西在表里没有落位 → 先改本文件（对齐规则），再写码。

## 二、区域地图与导航模型（定稿）

### 2.1 区域地图

```
┌────────────────────────────────────────────────────────────────────────────┐
│ 侧栏头 275px          │ 会话顶栏（flex）            │ 工作面板头 │ 窗口控制   │ 46px
├───────────────────────┼─────────────────────────────┼────────────┼───────────┤
│ ① 侧栏体              │ ④ 对话主区                   │ ⑤ 工作面板  │           │
│   ⌕ 搜索会话 / ＋新会话│   转录（正文列 760 居中）    │  页签条     │           │
│   会话（无工作区归属） │   ──────────────────────     │  内容区     │           │
│   项目 ▸ 工作区        │   composer 坞（760 居中浮起）│  360px      │           │
│     └ 近7天/近14天/更早 │                             │            │           │
│ ② 侧栏底：目的地图标 + 版本号                        │            │           │
└────────────────────────────────────────────────────────────────────────────┘
浮层：#locowrk-overlays（遮罩+弹窗）· popover（用量/通知/模型）· ⌘K 命令面板 ·
      toast 栈 · 右键菜单
```

| 区 | 职责 | 关键量 |
|---|---|---|
| ① 侧栏 | 会话运营 + 目的地入口 | 宽 `--lw-sidebar-w` = `clamp(240px, 275px, min(520px, calc(100vw - 320px)))`；底 = `--lw-bg-side`（**暗色比主区更深、亮色比主区更灰**） |
| ② 侧栏底 | 目的地图标（扩展 / 记忆 / 定时 / 设置）+ 通知入口 + 版本号 | 高 `--lw-toolbar-h` 46px，按钮 `--lw-ctl` 28px |
| ③ 会话顶栏 | 当前会话标题 + 新建 / 搜索 / 面板开关 | 高 46px，`position:absolute` 压在主区顶部，**无下边框** |
| ④ 对话主区 | 转录 + composer | 正文列 `--lw-content-max`（缺省 760，可调，§2.7） |
| ⑤ 工作面板 | 工具产物的第二展示面 | 默认 360px / 最小 244px / **无固定上限**（受 §2.5 三栏预算 cap），可最大化接管主区 |
| 窗口控制 | 最小化 / 最大化 / 关闭 | 浮在 46px 带右端，车道 `--lw-wincontrols` 120px |

**关闭的备选**（不做，勿再提）：底部状态栏（信息并入 ③ 与 composer，少一区=少一处分歧）、
右侧迷你导航轨（长会话实测后再议）、独立图标栏（见 2.4 说明）。

### 2.2 铁则：一条 46px 带，没有独立标题栏

参考对象**没有独立的标题栏组件**。窗口顶部唯一一条 chrome 带由三个区域的头**等高拼成**：

1. 侧栏头 / 会话顶栏 / 工作面板头 **高度一律 `--lw-toolbar-h`（46px）**，背景各自跟随所在列，
   相邻处**不设边框**，视觉连续；
2. 拖拽区**嵌在带内的空白处**（侧栏头的空白段 + 顶栏的标题段），**不放独立拖拽条**；
3. 带内一切按钮/输入一律 `no-drag`（`-webkit-app-region: no-drag` 或 Tauri 等价物），
   **按钮区禁止与拖拽区重叠**；
4. 带内控件高度一律 `--lw-ctl`（28px）——46 = 28 + 上下各 9px；
5. 窗口控制浮在带右端 `--lw-wincontrols`（120px）车道上（三个约 40×46 的平面字形按钮，
   图标 12px）。**面板关闭时顶栏右端预留该车道；面板打开时由面板头接管**（同一时刻只有
   一个区域为车道负责，避免两个区域各留一次造成空洞）；
6. 侧栏折叠后，侧栏切换按钮出现在顶栏左侧的 lead 槽——**该槽恒在**（展开时宽 0），
   它是零宽导致标题零跳变，**折叠不得使正文列位移**。

### 2.3 侧栏组织：工作区 → 时间桶（用户 2026-10-01 指定）

层级**固定两级**，不要再加一级：

```
会话                      ← 无工作区归属的会话（⑲ 之前的会话、纯数据目录会话）
项目
  ▾ 📁 Locowrk      •     ← 工作区（= fsRoots 里的一个根目录），尾随圆点 = 有会话在跑
      近 7 天
        ○ 设计 UI 界面…
        ○ ⑲ 会话持久化落盘
      近 14 天
        修复大文档卡死Bug
      更早
        熟悉项目结构
```

- **一级分组 = 工作区**（工作区 = 设置 → 开发者 → 工作区目录里的一个根目录，名字取末段）。
  **会话必须能回答"我属于哪个工作区"**——这是后端要补的一条关联（§8.2）。
- **二级分组 = 时间桶**：`近 7 天 / 近 14 天 / 更早`（按会话最后活动时间，前端即可算）。
- 分组头 28px 行：12px chevron + 14px 文件夹字形 + 13px 名称 + 可选 6px 状态点；
  hover `--lw-wash-2`；可折叠（折叠态持久化进 `sidebar 偏好`）。
- 会话行 28px、圆角 8px、`0 8px` 内边距、13px 文案、超长省略；工作区内的会话左缩进 28px
  （让出分组头的字形宽度），时间桶标签再缩进一档且用 11.5px `--lw-ink-4`。
- **选中行 = `--lw-wash-3` 填充，禁止左侧色条**（参考对象无色彩强调）；
  hover = `--lw-wash-2`；行尾 `…` 按钮仅 hover/选中时出现（重命名 / 删除 / 导出）。
- 运行中的会话：标题前 4px 脉动点（§6.6 唯一的常驻动画）。
- 侧栏头右侧 = 侧栏折叠按钮；**不放品牌名以外的内容**。
- **折叠**：宽 0（150ms），体不卸载（保滚动位置）。
- **拖拽调宽（照参考对象 `sidebar-resize.ts`）**：手柄嵌在侧栏右缘，`position:absolute;
  top:0; right:0; bottom:0; width:8px; cursor:col-resize; touch-action:none`；
  **范围 240–520px、缺省 275px**；可见提示 = `::after` 2×32px 圆角条（`--lw-ink-1` 20%），
  仅 hover / 聚焦 / 拖拽时显形，聚焦与拖拽时换 `--lw-accent`，聚焦不画外框（圆角条即焦点提示）；
- **拖拽中**根节点置 `data-sidebar-resizing="true"`，全局 `cursor:col-resize !important` +
  `user-select:none !important`（拖过正文不选中）；指针 `setPointerCapture` +
  pointerdown/move/up/cancel/`lostpointercapture`；
- **键盘可达**：`role="separator"` + `aria-orientation="vertical"` + `aria-valuemin/now/max`
  + `aria-valuetext`（"侧栏宽度 275 像素"）+ `tabIndex=0`；`←/→` 步进 16px、`Home/End` 到两端、
  双击复位；
- **宽度跨重启持久化**；**折叠 ≠ 宽度 0**：折叠是独立状态，展开时回到记住的宽度；
- **拖到小于最小值即折叠**——把"拖没了"变成一个明确状态，而不是卡在 240；

### 2.4 目的地与导航

**不引入独立图标栏**（与我 2026-10-01 首版提案不同，按参考对象实机纠正）：参考对象把目的地
做成**侧栏底部的图标按钮**，275px 的侧栏因此一栏两用，窗口顶部不再被第二栏切走宽度。

| 入口 | 位置 | 备注 |
|---|---|---|
| 对话 | 隐式（侧栏本身就是对话入口） | 不占图标位 |
| 扩展 / 记忆 / 定时 / 设置 | 侧栏底 4 个图标按钮 | 各 28px，图标 15px，`aria-pressed` |
| 通知 | 侧栏底图标（第 5 个），点开 **popover**，不是页面 | 见 §3.13 |
| 命令面板 | `Ctrl/⌘ + K` | 唯一「跳任何地方」的入口，§3.15 |
| 工作面板开关 | 会话顶栏右侧独立成组 | 只在对话目的地有意义 |

**目的地一律整页接管 ③④⑤**（用户 2026-10-01 纠正；参考对象源码 `page !== "chat"` 时渲染
整页路由，设置更极端——连 chat shell 都不渲染）。切换规则：

- **对话视图不卸载**：目的地切换时用 `hidden` + `inert` 把 chat shell 挂起，回来即恢复
  滚动位置与在跑的会话（参考对象先例）；
- 非对话目的地在侧栏右侧铺满（占据 ③④⑤ 的位置），**侧栏 ① 保持显示**（会话随时可切回）；
- 每个目的地的**页头形态固定**：20px 标题 + 右侧主按钮（accent 实心）+ `…` 溢出菜单；
  需要子页签时用 §3.2 的计数页签，不新开导航层。

### 2.5 工作面板

工具产物（diff / 文件 / 预览 / 工具产物 / 子 Agent 转录）的**第二展示面**——对话不再被
产物挤爆的关键。形态对齐参考对象：

- **宽度 = 三栏预算，不是固定上下限**（照参考对象 `work-panel-resize.ts`）：最小 244px、
  缺省 360px、**无固定上限**——上限 = `容器宽 − 侧栏宽 − 主区地板 450px`，宽窗口可以把
  宽度花在面板上；**主区地板 450px 是硬的**（= composer 工具条不折行的宽度），顶到地板时
  **先让侧栏折叠**，再谈面板；
- **拖拽柄**：`position:absolute; inset-block:0; left:-5px; width:10px; z-index:30;
  cursor:col-resize; touch-action:none`；可见提示 = `::after` 2×32px 圆角条（`--lw-ink-1` 20%），
  hover / `:active` / `:focus-visible` / 拖拽中才显形，聚焦与拖拽时换 `--lw-accent`；
  `:focus-visible` 不画外框（圆角条本身就是焦点提示）；拖拽中根节点置
  `data-work-panel-resizing="true"`，全局 `cursor:col-resize !important` +
  `user-select:none !important`；
- **键盘与复位**：柄 `tabIndex=0`、`role="separator"` + `aria-orientation="vertical"` +
  `aria-valuemin/valuenow/valuemax`；`双击 = 复位缺省宽`（clamp 到当前预算内）、
  `Home/End` 到两端、方向键步进 16px；指针路径用 `setPointerCapture` +
  pointerdown/move/up/cancel + `lostpointercapture`；
- 头部：`+` 新建页签（空态即**启动器清单**：审阅 / 文件 / 浏览器 / 子 Agent 转录 /
  工具产物）+ 页签条（可关闭）+ 最大化 / 还原 + 关闭；
- **插件可贡献页签类型与启动器条目**——这是「一切皆插件」在 UI 上的第一个真兑现点
  （参考对象里「Git 透镜」「依赖审计」就是这么来的），贡献项带 `插件` 徽章；
- **面板打开/宽度/页签是跨会话保持的壳状态**，不是某个会话的从属物。

### 2.6 保活与视图规则

| 视图 | 规则 |
|---|---|
| 对话 | `hidden` + `inert` 挂起（不卸载）——进行中的会话与滚动位置都不能丢 |
| 工作面板 | 同样挂起；打开态与宽度跨会话保持 |
| 其他目的地 | 按需挂载（`v-if`），离开即卸载 |
| 全局层 | 审批弹窗挂 App 根（跨视图弹出，§五）；toast / popover / 命令面板同样挂根 |
| 开发者面板 | 挂**设置视图内**（`developer` 分区 + 调试面板），不占目的地名额 |

### 2.7 主对话区列宽（第三条调宽轴，用户 2026-10-01 指出；参考对象 `ConversationWidthHandles` / D439）

**主区内容列自己也能调宽**，而且**与 composer 严格同步**。参考对象源码注释里记着一个真实 bug：
不显式同步"每条消息的正文宽"时，列加宽了而消息行冻在默认值上——**所以这条必须按"同源"来写**。

- **一个变量，三个消费点**：列宽偏好只存**一份**（`--lw-content-max`），同时喂 **转录列**、
  **composer 列**、**每条消息的正文宽**。三者同宽**是同一个变量保证的，不是三处各自对齐**——
  任何一处单独写死宽度都是 bug（§3.11 composer 已按此改）；
- **列宽是"偏好值"，实战宽度 = `min(主区宽, 偏好值)`**：侧栏展开或面板打开把主区挤窄时，
  列被自动压缩而**偏好值不被改写**；主区变宽后回到偏好宽度；
- **数值**：缺省 **760**、拖拽/键盘下限 **560**、单侧留白 **24**（→ 上限 = `主区宽 − 48`，
  留白是给调宽热区与 minimap 用的）。落地以 `shared` 的
  `DEFAULT_/MIN_CHAT_CONTENT_MAX_WIDTH`、`CHAT_CONTENT_WIDTH_GUTTER` 为唯一真源，本文不复制为第二份常量；
- **双柄、中心对称（"对等"的准确含义）**：左右各一个柄，柄的位置由列宽与中心算出
  （`max(0, (100% − 列宽) / 2 − 6px)`），**两柄改的是同一个偏好值**，列始终居中。
  **指针位移 1px ⇒ 列宽变化 2px**（左柄 `start − 2Δ`、右柄 `start + 2Δ`）——
  因为动一边等于两边对称各动一半。这一条不写清楚，实现者一定会写成 1:1 而后发现"拖不动/拖过头"；
- **触发区 = 12px 隐形热区**（`cursor: col-resize`、`pointer-events: auto`；容器
  `pointer-events: none` 且 `inset: 0 0 <composer 高>` ——**热区下沿停在 composer 顶部**，
  不许覆盖输入框，否则点输入框会变成拖宽）；
- **可见提示 = 2×40px 圆角竖条**，竖直居中，`--lw-ink-1` **18%**（暗）/ **12%**（亮，
  刻意更淡——同一条规则在亮色下不该读成"亮缝"）；静止不可见，hover / focus-visible 淡入；
  **拖拽中高度 40 → 56px、加深到 32%（暗）/ 20%（亮）**（"变长变深"＝正在拖）；
- **聚焦不画外框**，改用 `box-shadow: 0 0 0 2px color-mix(accent 22%)` 软环
  （柄没有填色底，硬外框会显得飘在半空）；
- **拖拽中零延迟**：拖拽期间临时把列宽过渡关掉（`transition: none`）——列宽必须跟手；
  仅**程序化改宽**（双击复位 / 键盘 / 窗口变化）才走 §6.6 ④ 的滑动过渡；
- **性能**：`pointermove` 用 `requestAnimationFrame` 节流，每帧最多一次渲染；
- **键盘**：`role="separator"` + `aria-orientation="vertical"` + `aria-valuemin/now/max` +
  `aria-valuetext`（"对话宽度 760 像素"）+ `tabIndex=0`；`←/→` 步进 **16px（Shift = 32px）**，
  方向按柄的 `data-side` 判定（左柄 ← 变宽、右柄 → 变宽）；`Home` = 复位缺省；
  `End` = 最宽（按当前主区宽 clamp）；**`Esc` 取消本次拖拽**；
- **取消语义**：`pointercancel` 与 `Esc` 都回到**起始宽度**且**不落盘**——取消就是取消，不留痕；
- **双击 = 复位缺省 760**（并落盘）；
- **持久化走设置、不走 localStorage**：列宽是"设置"级偏好（随设置同步/备份），落在 settings 的
  `chat.contentMaxWidth`（§3.2 `ChatSection`）；写失败只留 live 值，下次拖拽重试；
- **实时上限**：用 `ResizeObserver` 跟主区宽，`clamp(偏好值, 560, 主区宽 − 48)`——
  窗口缩小后旧偏好值不会溢出；
- **不参与三栏预算**（§2.5）：列宽只是主区内部的 `max-width`，**不占用布局宽度**——
  所以 **450px 主区地板仍然是硬的**，列宽偏好再大也挤不掉面板与侧栏。

## 三、页面模式库

### 3.1 列表页模式（`components/patterns/ListPage.vue`）

一切"条目集合"页面共用：**页头（标题 + 主按钮 + `…`）→ 页签/筛选 chips → 内容区
（行卡列表，空态优先）→ 底部批量操作栏（`batching` 时显示）**。

- 行内容与动作由使用方以默认插槽提供；模式组件不认识业务类型。
- 行 = `--lw-wash-1` 圆角 14px 卡片（**不是表格线**），`14px 16px` 内边距，行间 `gap: 8px`。
- `v-model:search` 未绑定 → 搜索框整个隐藏；`filters` 未传 → chips 行隐藏。
- 批量栏内容经 `#batch` 插槽；**批量卸载必须二次确认并列出插件名**（见清单）。
- 第二排 chips：`subFilters` / `v-model:subFilter`（闲置档位与状态档分离）；不传不渲染。
- 实例：扩展-已安装页、扩展-市场页（市场用卡片网格变体）、记忆页。

### 3.2 设置分区模式（`components/settings/`）

### 3.5 数字呈现规范

面向用户的数字用人类尺度的档位与取整，不暴露机器精度的原始值；能显示比例就优先显示比例。

| ❌ 机器语言 | ✅ 人的语言 |
|---|---|
| 262,144 token | 256K |
| 52,428.8 token | ≈51.2K（`compactNumber` 按 1024 进位） |
| 102,400 字节 | 100KB |
| 1790770863（时间戳） | 3 天前 |
| 87 个工具 / 20 个暴露 | 已优化 87 → 20 |

- 大数用档位（K/M/G）、小数取整、单位不重复（写 `256K`，不写 `256K token`）。
- 前端统一走 `lib/format.ts` 的 `compactNumber` / `clip` / 相对时间，**组件不许各自手写换算**。

### 3.6 会话侧栏 = 会话列表（替换原「会话切换器」）

⑲ 的最小切换面（顶栏下拉）**退役**，由 §2.3 的侧栏取代：

- 数据源 `session_list`（mtime 降序 + 首条用户消息截断做标题），前端补工作区归属与时间桶；

- 新会话 = 前端生成 id + 清空视图；**首条消息发出前不创建任何后端状态**；

### 3.7 轮次过程组（`components/chat/TurnProcess.vue`）—— 密度治理的第一道闸

**一轮助手的"过程"整体折叠成一行**，只留结论在外面。这是参考对象最值得抄的一条：

### 3.8 工具行（`components/chat/ToolRow.vue`）—— 原「工具调用卡」降级为行

工具执行过程**默认折叠**的对话密度铁则（不折则一屏被参数/结果 JSON 刷满）：形态从
「卡片」降级为**行**——去掉卡片边框，用 wash 分层。

- 折叠态 = **单行**：字形 + **动作名（中文，13px，`--lw-ink-2`）** + **加工后的参数摘要**
  （mono 12.5px `--lw-ink-3`，规则见 §3.18）+ 右侧状态（`已完成` 前置 6px `--lw-ok` 圆点 /
  `运行中` 前置脉动点 / `失败` 用 `--lw-danger`）+ hover 才出现的复制按钮。
  **禁止裸显工具 id**（`fs_edit` / `shell_read` 只允许出现在展开明细、tooltip 与调试面板里）。
- 展开态 = 明细块：`--lw-bg-inset` 底、圆角 10px、`10px 12px` 内边距、mono 11.5px，
  分「参数 / 结果」两段（结果失败态显示 error 文本，danger 色）；
- **写/编辑类工具在折叠行尾带变更统计**：`+N −M`（`--lw-ok` / `--lw-danger`）与产物大小
  （如 `7.9 KB`），mono 11.5px —— 不展开也能判断"改了多少"；非写类工具无此项，整块不渲染；
- **失败自动展开一次**（`!pending && ok === false`，含历史重放挂载即检）——错误可见性
  优先于密度；用户可手动再折叠；
- 相邻同工具的连续调用**合并进 §3.7 的过程组**，不在行层面再合并。
- **折叠交互铁则（本行与 §3.7 的过程组共用同一套）**：**每一个过程组、每一个工具行、
  每一条思考行都必须能独立展开与收起**，且都是真 `<button>`（`aria-expanded`、键盘
  `Enter`/`Space` 可达、焦点环可见）。**默认态：一律收起**——包括正在运行的过程组
  （用户 2026-10-01 裁定："默认就是收缩状态，用户自己点击展开"）。**唯一例外是工具失败**，
  自动展开一次。**设置 → 对话**提供 `默认展开工具执行过程`（缺省关）：开启后新发的轮次默认展开。
  **用户手动切过的单元，当轮内不再被默认态覆盖**；展开体一律 `v-show` 保留 DOM
  （历史重放的展开态才便宜）；禁止"点了没反应"或"整块一起开合"——折叠粒度就是上面三级。

### 3.11 composer 坞（`components/chat/Composer.vue`）—— 原 `PromptBar.vue`

- 转录滚动区在 composer 高度上做**底部渐隐 mask**，而不是盖一条不透明底带
  （底带会盖掉主题背景，也会形成"两条带"的错觉）；
- 上行 = 自适应高度文本域（1 行起，不设边框、透明、14px / 1.45，占位符 12.5px `--lw-ink-5`：
  `输入 / 使用命令 · @ 引用文件`）；

  - 左：28px 圆形 `+`（附件）→ 权限模式 chip（如 `全自动`，圆角全、`--lw-wash-2` 底、
    12.5px、带 chevron）→ 模型 × 推理档 chip（同形态）；
  - 右：**用量环按钮**（`◐ 14%`，点开 §3.12 浮层）→ 模型 chip 的第二个触发点可省
    （同一 chip 兼作菜单触发）→ sparkle（提示词增强）→ **36px 圆形发送键**：
    空闲 = `--lw-accent` 实心 + 上箭头（`--lw-accent-ink`）；**运行中 = 同一位置换成方块
    停止字形**；禁用 = `--lw-wash-3` 底 + `--lw-ink-4` 字形；
- 宽度自适应：**模型 chip 是唯一可收缩的 flex 项**（`min-width:0` + 文本省略），
  其余控件 `flex:0 0 auto` —— 窄窗口下工具条会溢出卡片（原型实测 1120px 溢出 105px，
  已修，此处成规）；
- `Enter` 发送 / `Shift+Enter` 换行 / 运行中 `Enter` 排队或忽略（跟 settings 的
  「回车发送」开关走）。

**权限模式 chip 的菜单（子件 `ComposerPermissionChip.vue`）**——位置就是"会话输入框旁边随手切"
（《Setting and Constrained Optimization.md》§4 的裁定，**不是设置里的深层选项**）：

- 点 chip → **向上开** popover（composer 贴窗口底，只能向上），宽度随内容（约 120–140px），
  行高 30px、13px 文案、左对齐、选中行尾挂 `✓`——**不用彩色、不用单选圆点**；
- 档位 = 项目已裁定的**四档**（同一份裁定，不自造；参考对象的三档 每次询问 / 允许编辑 /
  全自动只是同一梯子的更粗分法——**形态照抄，档位按本项目裁定**）：

| 档位 | 行为 |
|---|---|
| 计划 | 只有 `Pure` 放行，写操作全拒 |
| 变更前确认 | `Pure` 放行；`Compensable` 挂 warn 徽章；`Irreversible` 挂 danger 徽章 + 弹窗 |
| 自动编辑 | `Pure` + `Compensable` 放行；只有 `Irreversible` 弹窗 |
| 完全访问 | 全部放行，只记审计日志 |

- **三类硬底线在任何档位下生效**（路径逃逸 / SSRF / ABI 边界）——「完全访问 ≠ 无安全」：
  chip 只切**审批门的预答策略**，绝不切安全边界；危险档位的 chip 旁允许挂一个 `ⓘ`，
  但**不加色、不加动效**（单色纪律，§6.1）；
- 档位是**会话级**（记在会话上、跨轮保持、随会话持久化），不是全局设置；
  settings 只提供**新会话的缺省档**；
- **边界**：参考对象把「权限」（ask / accept-edits / auto）与「默认模式」（智能体 / 规划 /
  目标）做成**两个独立控件**。Locowrk 的四档把"计划"折进了权限梯子（项目自己的裁定，照办）；
  将来若加"默认模式"轴，**必须是 chip 旁边第二个独立控件，不得折进这个菜单**——
  一个菜单里混两个语义轴，用户无法从文案推断后果。
- **chip 显示"实际生效档位"，不显示"用户选的档位"**：若某个工具的审批被强制拦下
  （硬底线 / 子 Agent 冒泡 / 沙箱自身拒绝），chip 必须反映**当时真正生效的档位**，
  否则用户会看到"完全访问"却仍被拦，以为自己的设置没生效——
  **档位标签是状态显示，不是愿望显示**。

### 3.16 子 Agent 转录（工作面板页签，`components/shell/SubagentTranscriptTab.vue`）

§3.10 的子 Agent 卡是**入口**，这里是**子会话自己的转录**。⑮ 的"子内活动不投影"约束的是
**父会话转录**，不是"用户不能看"——想看时必须有地方看得到（本项目的可见可审计取向）。

- 页签名 = 子 Agent 名（如 `ui-designer`）+ bot 字形；可关闭、可与审阅/文件等其他页签并存；
- 页内**复用 §3.7–3.9 的同一套行语法**（过程组 / 工具行 / 思考行）——子转录不是第二套 UI，

- **composer 在本页签禁用**，底部固定一条说明：`子 Agent 由主 Agent 驱动，无法在此输入。`

### 3.17 审批决策卡（`components/chat/PermissionCard.vue`）—— 审批**不是弹窗**

**规则修正（2026-10-01，用户指出我原设计"不行"）**：审批原定形态是居中 Modal + 遮罩，
参考对象实机**不是**——它是**转录流里的内联决策卡**（`PermissionCard.tsx` /
`.permission-card`）。用户能继续读上下文、能滚动、能在决策前先去看别的东西；
"必须决定才能继续"由**内核的轮次阻塞**保证，**不由遮罩保证**。这两件事本来就不该混为一谈。

- **容器**：`<section role="region">`，宽 = 正文列（`min(100%, var(--lw-content-max))`）、`margin:10px 0`、
  内边距 `14px 16px`、圆角 12px（`--lw-r-md`）、**无边框**；风险靠**染底 + 胶囊**表达
  （平面内组件无边框纪律，§6.1）。
- **风险三档**：高（缺省，宁严勿松）= `--lw-danger` 7% 染底 + `高风险` 胶囊
  （danger 14% 底 + danger 字）；中 = `--lw-warn` 7% 染底 + `中风险` 胶囊；
  低 = 无染底（`--lw-wash-1`）+ `低风险` 胶囊（`--lw-wash-3` 底 + `--lw-ink-2` 字）。
  副作用映射：`Irreversible → 高`、`Compensable → 中`、`Pure → 低`（理论上不出现）；
  **载荷缺风险字段一律按"高"**（与「side_effect 缺失按 Irreversible」同一纪律）。
- **卡片自上而下六段**（照实机）：① **头行** = 标题 `需要权限`（13px / 600 / `--lw-ink-1`）
  → 左推 → 排队数（`还有 N 个待处理`，10.5px `--lw-ink-3`，仅 N>0 时渲染）→ 风险胶囊（最右）；

  ③ **理由行**（可选）= `{该工具会做什么}`（如"会修改你工作区里的文件"），12px `--lw-ink-3`；
  ④ **参数区** = 标签 `输入`（10.5px `--lw-ink-4`）+ 右上角复制按钮 +
  **复用 §3.8 工具行的参数呈现**（shell 类 → 命令块 / 文件内容 → 代码块 / 其余 → 带标签字段），
  `--lw-bg-inset` 底、圆角 10px、`max-height:240px` 滚动（**不再裸贴 JSON `<pre>`**）；
  ⑤ **环境行** = `项目 {工作区名或路径}`（12px `--lw-ink-3`，超长省略、`title` 给全路径；
  无工作区写 `临时会话`）——**批准前必须知道"这条将在哪儿跑"**，这是 ⑱ fs roots 的 UI 兑现；
  ⑥ **动作行** = 左：超时提示 `若 100 秒内未响应将自动拒绝`（10.5px `--lw-ink-4`）；

- **三键（不是两键，这是真缺口）**：`拒绝`（ghost，不执行、轮次带失败收束）·
  `允许本次对话`（secondary，该工具**本会话内不再问**——与 §3.11 权限 chip 同一套会话级
  策略语言，**不越过三类硬底线**）· `允许一次`（**primary**，accent 实心，只批这一次）。
  主按钮 = `允许一次`：**最小授权是默认路径**，"允许本次对话"要主动多按一次。
  风险由染底与胶囊承载，按钮只回答"哪条是默认路径"——不用红色按钮。
- **超时自动拒绝（新行为，照实机）**：卡片置位即启动倒计时，超时按 `拒绝` 收束（fail-closed）；
  只显示秒数文案，**不做进度条动画**（§6.6 动效清单外）。阈值需后端定时器（§8.2），
  是否沿用 100s 见 §8.3。
- **决策中防重**：三键同时置 disabled；命令报错 → toast + 恢复可点，卡不消失。
- **决策后焦点回到 composer 输入框**——批完立刻能接着打字。
- **卡不在视野内的兜底**（Locowrk 补的一条）：决策未决时该会话在侧栏行挂**待决标记**，

- **批量卸载的二次确认仍是 Modal**（§五）：有遮罩的地方必须是"不答就不能做别的事"
  （名单 / 数量 / 破坏范围一次说清）；**审批不满足这条**，所以审批从 Modal 出列。
- **决策后：卡片降级为一条转录记录，不无声消失**（用户 2026-10-01 指出）：点任一键后，
  卡片**原位**换成一条会话内系统消息（§3.3 形态，key `notice.approvalResolved`）：
  `已允许一次 · shell` / `已拒绝 · fs_edit` / `已允许本次对话 · shell`，带可选动作
  `查看参数`（重开**只读**的参数明细）。**"做过什么决定"是可审计事实，不只是"弹窗关掉了"**。
- 被拒的那次调用**同时补一条失败的工具行**（状态 `已拒绝`，danger 色，展开可见拒绝理由）——
  让"这一轮为什么没做完"在转录里自洽，而不是留一个悬空的工具行。
- 记录条**不可再编辑**（不再是决策卡）：决策一旦做出就不再是待决态。

### 3.18 工具与动作的人类呈现（工具 id 不许直显）

用户 2026-10-01 裁定：**所有动作与工具都必须显示中文名**，不许把 `fs_edit` / `shell_read`
这类内部 id 直接甩给用户；**参数摘要必须加工过，不许裸复制命令**。

**动作名映射**（落 `locales/{zh-CN,en}.ts` 的 `tool.action.*` 区，是 i18n key 不是硬编码中文）：

- `shell` / `shell_read` → **运行**；`sandbox_run` → **沙箱运行**
- `fs_read` → **读取**；`fs_write` → **写入**；`fs_edit` → **编辑**；`fs_delete` → **删除**；
  `fs_restore` → **恢复文件**
- `git_status` → **查看状态**；`git_diff` → **查看差异**；`git_commit` → **提交**；
  其余 `git_*` → **Git 操作**
- `memory_write` → **记住**；`memory_read` / `memory_search` → **检索记忆**
- `search_tools` → **检索工具**；`subagent_run` → **派生**；`schedule_create` → **创建定时任务**；
  `notify` → **发送通知**
- `mcp_*` → **MCP：{server} 的 {tool}**（server / tool 取真名做参数）
- 表外工具（第三方插件）= 取 manifest 的本地化 `name`；**manifest 没给 name 时回落工具 id
  并附 `插件` 徽章**——回落是例外，不是常态。

**参数摘要的加工规则（按工具类型分派，不是统一 clip 原始值）**：

- **命令类**（`shell*` / `sandbox_run`）：**先剥包装**——去掉 `cd "<路径>" && …` 前缀、
  去掉最外层 `bash -lc "…"`；`&&` 串联时只显示第一个有意义的命令，其余记 `… +N`；再 `clip`。
  **严禁**把 `cd "$PI_SCRATCH_DIR" && sed -n '236,252p' verify3.mjs` 原样倒出来。
- **文件类**（`fs_read` / `fs_edit` / `fs_write` / `fs_delete`）：摘要 = **工作区相对路径**
  （能相对就相对）+ 行数或变更统计（`292 行` / `+42 −18`）。**不显示绝对盘符**——
  `C:/Users/42527/…` 是噪声，全路径留给 tooltip 与展开明细。
- **对象类**（参数是 JSON 对象的工具）：显示**键值的自然语言摘要**——取 1–2 个最有信息量的
  值（`prompt` / `query` / `url` / `key`）写成 `键：值`，**绝不显示 `{`、`}` 与引号**；
  多余键记 `… +N`。
- **分支/服务器类**（`mcp_*`）：摘要 = `{server} / {tool}`。
- 兜底：`clip(第一个原始值, 48)`（现状行为），**仅当上面全部不匹配时**使用。

**"思考"行同理**：推理原文里的 markdown 记号（`**`、反引号）与多余换行在**摘要态**剥掉，
只留纯文本首句；原文在展开态照原样呈现（不篡改事实）。

**展开态才是"诚实面"**：参数原样（pretty JSON）、结果原样、全路径、工具 id 与版本、
副作用徽章都在那里。**摘要态人话、明细态原样**——两态各司其职，不许把明细的原始性搬到摘要里。

### 3.19 控件族（表单与按钮，两主题共用）

**唯一允许的控件形态表**；新控件先在此扩表再上页面。控件高度统一 `--lw-field-h`（≈38px），
图标控件统一 `--lw-ctl`（28px），圆角取 §6.3 阶梯。

- **按钮**：内边距 `7px 12px`、13px、gap 6px、`:active` 缩放 0.98（150ms）。三变体：
  `primary`（`--lw-accent` 底 + `--lw-accent-ink` 字）/ `secondary`（`--lw-wash-2` 底）/
  `ghost`（无底无框，hover `--lw-wash-2` + `--lw-ink-1`）。**禁用 = opacity .55 +
  `not-allowed`，不改色**（改色会与"危险"语义撞车）。
- **图标按钮**：`28×28`、圆角 12、透明底、`--lw-ink-2`，hover `--lw-wash-2` + `--lw-ink-1`；
  字形 15px（窗口控制 12px）。**必有 `aria-label`**。
- **字段**：`padding 9px 11px`、`min-height --lw-field-h`、`--lw-wash-2` 底、**无边框**；
  聚焦 = 底换 `--lw-raised` + `box-shadow: 0 0 0 2px color-mix(accent 22%)`；
  占位符 `--lw-ink-5`；`readonly` / `disabled` 降为 `--lw-ink-3` + `cursor: default`；
  密码框右侧内嵌 reveal 按钮（故 `padding-right: 34px`）。
  **select 与 input 必须等高**——native select 闭合盒天然矮约 2px，一律用 `min-height` 锁死，
  **不许各页自己调**。
- **开关**：`32×20`、圆角全。关 = `--lw-wash-3` 底 + 1px `--lw-line-strong` 环 + 旋钮
  `--lw-ink-4`（暗）/ 白（亮）居左；开 = `--lw-accent` 底 + 旋钮 `--lw-accent-ink` 居右。
  **极性翻转**（旋钮颜色也跟着反，不只滑动）。无文案，语义由左侧行标题承担。
- **分段控件**：轨 `--lw-wash-2` + 圆角全 + 2px 内边距；项 `5px 12px`、12.5px；
  选中项 = `--lw-raised` 底 + `--lw-shadow-raised`（**"抬起"而非变色**）。二到四选一用它。
- **下拉**：任何"看起来像输入框"的下拉必须与字段同高同形；触发器与菜单分离
  （触发器可以是一个 chip）。
- **数字输入**：右对齐、宽 140px、可带单位后缀（`%` / `秒` / `token`）。
- **复选框**：16×16、圆角 4、1.5px `--lw-ink-2` 边；选中 = `--lw-accent` 底 + `--lw-accent-ink` 勾；
  禁用 opacity .4。
- **帮助提示 `ⓘ`**：跟在行标题或字段标签后的一个小字形按钮（`cursor: help`，`aria-label`
  即解释文案），hover / 聚焦弹 tooltip（§3.21）。**解释文案只放这一处**——行里不再多写一行说明：
  "行标题 + 右侧控件"是行卡唯一常态，解释是**按需展开**的。
- **行卡**（设置与列表共用）：`--lw-wash-1` 底、圆角 14、`14px 16px`、flex space-between、
  gap 24；行标题 13.5px / 500 / 1.3；可选 detail 12px `--lw-ink-2`（**放"当前值"不放解释**）；
  控件列 `flex:0 0 auto`、右对齐、`max-width 240px`。
- **徽章**：圆角全、`2px 8px`、11px；中性 = `--lw-wash-3` 底 + `--lw-ink-2` 字；语义 =
  该色 16% 底 + 该色作字（§3.4 分族）。

### 3.20 右键菜单与行尾 `…` 菜单

同一套浮层形态，`min-width 184px`、宽随内容、`padding 5px`、圆角 14、

### 3.21 Tooltip

- 短提示（按钮名、快捷键）：`padding 3px 7px`、圆角 10、11px、`--lw-raised` 底 +
  `--lw-shadow-raised`、`--lw-ink-2` 字、**单行不折**；
- 长解释（帮助文案、完整路径、参数全文）：`white-space: normal`、
  `max-width: min(360px, calc(100vw - 16px))`、左对齐；
- 一律挂 `body`（否则被壳的 `isolation: isolate` 困在遮罩下），`z-index 60`，`pointer-events: none`；
- **键盘可达性由 `aria-label` 承担**（tooltip 是鼠标增强，不能是唯一通路）；
  延迟 400ms 出现，移开即消失，不做淡入淡出以外的一切效果。

### 3.22 Toast

栈挂窗口右下（`z-index 50`，距边 16px，纵向 gap 8px），**同屏最多 3 条**，超出排队。

- 单条：`min-width 280px / max-width 420px`、`padding 12px 14px`、圆角 12、
  `--lw-bg-elevated` + `1px --lw-line` + `--lw-shadow-dialog`；
- **左侧 6px 状态点（ok / warn / danger），不给整条染底**——染底会把"信息"变成"警报"，
  用户会开始无视 toast；
- 标题 12.5px `--lw-ink-1`、正文 12px `--lw-ink-3`；可选一个 ghost 动作（如 `查看详情`）；
- 自动消失 4s（带动作按钮的 8s），**hover 暂停计时**，`Esc` 关栈顶；
- 入场 = 淡入 + 右侧滑入 8px（§6.6 动效②）；
- **toast 只承载"刚发生的事"**：需要用户处理的（审批、待决）不许只发 toast——它会被无视。

### 3.23 加载态与骨架

**三种加载形状各不相同**（不要一律转圈）：

- **目的地懒加载**：路由区居中一个 18px 旋转指示器（700ms linear）。**不铺骨架**——
  页面结构未知时铺骨架是骗人；
- **会话冷切换**（切会话正在重放日志）：对话顶栏下方一条 **2px 高进度轨**，28% 宽的不定段
  720ms 来回扫；composer 置 `pointer-events: none`（不能往正在离开的会话发消息）；
- **向上翻旧消息**：列表顶部一条 `min-height 26px` 的 12px 文案 + 12px 下边距；
- **骨架屏**只在**结构已知**时用（列表条目、插件卡）：骨架块高 10px / 圆角全 /
  `--lw-wash-2` 底，1.4s 呼吸（归 §6.6 的"运行指示"同类）；
- **加载与空态必须可区分**：加载中不给"暂无数据"文案（那是撒谎），空态不给骨架（那是拖延）。

### 3.24 启动与控制面（参考对象有、本项目至今缺失）

- **启动画面**：`position: fixed; inset: 0; z-index 1300`，居中品牌标记 72px + 名称
  16px / 600 / `-0.02em` + 一条 120×3px 的不定进度条。**只在冷启动出现**，壳就绪即淡出 200ms；
- **启动恢复面**：冷启动超过 8s 未就绪 → 换成**可操作**的恢复面（阶段文案 + `重试` +
  `打开日志`），`z-index 1400`。**永远不要给用户一个只会转圈的窗口**；
- **内核/后端不可用横幅**：嵌在 46px 带之下、内容区之上的一条，warn / danger 7% 染底 +
  左侧 6px 状态点 + 一行文案 + 可选 `打开日志`。**致命态才用 danger 染底并阻断交互**，
  可恢复态只用 warn 且不阻断；
- **更新提示条**（`z-index 45`）：同横幅形态，但只在有新版时出现，右侧一个 `查看` +
  一个关闭按钮；**不自动跳转、不遮内容**。

### 3.25 键盘快捷键（Locowrk 落地表）

- `Ctrl/⌘ + K` → 命令面板（§3.15，唯一"跳任何地方"入口）
- `Ctrl/⌘ + B` → 折叠 / 展开侧栏；`Ctrl/⌘ + J` → 折叠 / 展开工作面板
- `Ctrl/⌘ + N` → 新会话；`Ctrl/⌘ + ,` → 打开设置目的地
- `Ctrl/⌘ + [` / `]` → 会话前进 / 后退（沿侧栏顺序）
- `Esc` → 关当前浮层（栈顶）；无浮层时把焦点从输入框交出
- `↑`（输入框为空时）→ 召回上一条输入
- `Ctrl/⌘ + Shift + L` → 全局显示 / 隐藏主窗口（既有全局快捷键，不改）

**规则**：每个快捷键都要能在命令面板里**按名字搜到**（否则用户学不到）；键位只走
设置 → 快捷键，不在别处硬编码；与输入框冲突时**输入框优先**（`Esc` / `↑` 靠输入框空态判定）。

### 3.26 选择与光标纪律

- **默认不可选**：界面默认 `user-select: none`（桌面应用不是网页，误选会让人以为能复制）。
  **白名单**才可选：`input` / `textarea` / `[contenteditable]` / `.selectable`
  （助手正文、代码块、工具行内容、id / 路径 / 参数）/ 用户消息气泡。
  白名单容器里的 **`button` 重新置为不可选**（否则"复制"按钮的图标会被选进去）；
- **光标**：可点 = `pointer`；禁用 = `not-allowed` + opacity .55；拖拽柄 = `col-resize`；
  帮助 = `help`；拖拽进行中全局强制 `col-resize` / `grabbing` + 禁选（§2.3 / §2.5）；
- **选中样式**：`::selection` 用 `color-mix(--lw-ink-1 18%)` 底，**不用系统蓝**（单色纪律）。

### 3.27 窗口尺寸与退让顺序

- **最小窗口宽 1024px、最小高 640px**：`450`（主区地板）+ `244`（面板最小）+ `240`（侧栏最小）
  + 边距 + 窗口控制车道 ≈ 960，取 1024 留余量；
- **首次启动** 1280×820 居中；**不记住窗口尺寸**（那是窗口管理器的事，应用不自作主张）；
- **视口变窄的退让顺序固定**：① 面板先缩到 244 → ② **侧栏折叠** → ③ 面板继续缩到
  244 之下（紧凑档 1px，由"侧栏重开"路径临时借用）→ ④ **主区守 450 地板不动**；
- 用户把窗口拉到 < 1024 时同样按上述顺序，**宁可面板小到 1px，不可把对话压坏**。

### 3.32 设置页整页组装（本轮原型未覆盖，规范在此补齐）

设置是**独立的壳模式**，不是"对话区里换个内容"：参考对象在 `page === "settings"` 时
连 `.app-chat-shell` 都 `hidden` + `inert`，**整个对话壳不渲染**。Locowrk 同此：设置页自带
46px 带（头 = 导航轨顶部：拖拽区 + 搜索框），**不复用会话顶栏**。

**板面切换模型（v3.4，用户 2026-10-02 裁定，替代 v3.3 的"长页堆叠 + 滚动侦测"）**：
导航轨点击 = **切换当前分区板面**——右栏同一时刻只渲染当前分区的分区组件，分区之间
不堆叠、无滚动定位、无滚动侦测、无锚点闪烁；页头标题跟随当前分区。当前分区状态放壳
store（跨目的地往返与重启内会话保持）；⌘K 命中设置分区 = 打开设置目的地并直接切到该
板面（板面切换即定位；§3.15 的"闪一下"随滚动定位一并取消）。搜索过滤只作用于导航轨
候选，命中后点击即切板面。

**一、导航轨是"数据驱动的扁平索引"，不是手写 JSX**（参考对象最值得抄的一条架构决定）

- 每个分区声明一条记录：`{ id, group, labelKey, icon, searchKeys }`；**同一个索引同时喂导航轨
  与 ⌘K 命令面板**（参考对象放在 `lib/settings-search` 共享模块）。这样"新增分区忘了加搜索"
  这类漂移在结构上不可能发生；
- 落点：新建 **`lib/settings-index.ts`** 作为唯一真源；§3.2 的"settings.json 分区 ↔ 面板分区
  一一对应"由它机械保证（对不上就是构建期错误，不是运行时才发现）；
- 导航轨渲染 = 按 `group` 分组、组内**按索引顺序**出项（不排序，顺序即索引顺序）。

**二、Locowrk 的 12 个分区 → 4 个组**

- **偏好**：外观（appearance）/ 语言（locale）/ 对话（chat）/ 快捷键（shortcut）
- **智能体**：模型（llm）/ 上下文（context）/ 记忆（memory）/ 嵌入（embedding）
- **能力与安全**：插件（plugins）/ 命令终端（shell）/ 工具与分发（tools）（用户 2026-10-02 裁定：设置页展示名去「暴露」字；机制名 exposure 不变）
- **系统**：会话与数据（dataDir + 保留策略）/ 关于与更新

组标签 11.5px `--lw-ink-4`；实验性分区在项尾挂 `实验`（warn）徽章；
**插件可贡献设置目的地**——导航轨末尾一个「扩展」组（参考对象 `settings.groupExtensions`
先例），贡献项带插件图标。这与 §2.5「插件贡献面板页签」是**同一套贡献机制**的两个落点，
不要各写一套。

**三、搜索**

- 轨顶圆角搜索框（§3.19 字段形态）；**搜分区名 + 分区内每一行的标题文案**（行的 i18n key
  在索引里预声明，所以搜索是"索引驱动"而不是"渲染后爬 DOM"）；
- 无结果给一行 `没有匹配的设置`；搜索时只留命中项，**组标签随之变空则隐藏**；
- **从 ⌘K 命中进入设置时：直接切到该分区板面**（板面切换即定位；v3.4 起无滚动无闪烁）。

**四、保存模型：就地保存，没有全局"保存"按钮**

- 行内改动即写 settings（§五"默认不弹"纪律）；成功**不弹 toast**，失败走 §3.22 + 行内错误条；
- 立即生效类（主题 / 语言 / 字号 / 对话行为）不加确认、不留"未保存"态；
- **需要重启才生效的项在行下写明**（如命令终端的高危解锁），不许只靠 tooltip。

**五、恢复面（参考对象 `settings-recovery` 先例）**

settings.json 读取或解析失败时**绝不空白页**：给一个居中的恢复面（错误摘要 + `打开设置文件` +
`恢复默认` + `重试`）。理由与 §3.24 启动恢复面同一条：**设置页坏了，用户就失去了唯一的自救入口**。

**六、关于与更新分区**

版本行（应用 + 协议 + 内核）+ `检查更新` + `打开日志` + `打开数据目录` + 更新方式选择。
参考对象把这些集中在「信息」一页，Locowrk 照此。

**七、内容区版式（单板面内）**

分区标题在板面页头（56px，20px/600）；正文列（760）居中（板面切换模型下右栏一次只
渲染一个分区，v3.3 的"分区之间 gap 32px"随之失效）。多块板面用 13px/600 小标题分块，
块下说明 11.5px ink-4。**不做**"立即应用 / 取消"两按钮（那是移动端模式）；**不做**
设置项之间的联动禁用动画（禁用态直接呈现，§6.6 未列此类）。

**设置行版式（v3.5，用户 2026-10-02 裁定：设置行 = 左设置名、右设置参数/按钮；
参考对象 `.settings-row` / `.settings-toggle` 逐值照搬）**：

- **行 = 一张瓦片卡**（不是"组卡 + 行间发丝线"）：`SettingsRow.vue` 根 = flex
  items-center justify-between、gap 24px、内边距 14px 16px、圆角 14、底 wash-1；
  行与行 gap 6px 纵向堆叠——**行间空隙替代发丝线**（与插件索引同一节奏）；纯行板面
  列容器透明，混合内容（编辑器、快照面板）才整块一卡；
- **左 = 行名**：13px/500 ink-1 + 可选行下说明（11.5px ink-4）；行的**动态取值**
  （当前值 / 建议值 / 警告）也走左侧第二行（12px ink-3），不往右列挤；
- **右 = 控件列**：`flex: 0 0 auto`、右对齐、垂直居中、max-width 240px、min-height
  38px（= field 高——开关行与下拉行同高）。数字输入 140px、文本输入 min 140 自适应、
  下拉随内容；行名带 `label for` 指向控件；
- **开关（新增形态 `SettingsToggle.vue`）**：32×20 全圆角轨道 + 16px 滑钮（左 2 上 2，
  on = translateX(12px)）；off 轨 = `--lw-switch-track`（hover 0.18 档），on 轨 =
  accent（hover accent-hover），on 钮 = accent-ink、off 钮 = `--lw-switch-knob`；
  focus 环走全局 `:focus-visible`；disabled 半透明 + not-allowed；过渡 §6.6
  fast/ease-out 只动颜色与 transform；`role="switch"`。**设置行内的布尔项一律用
  开关，复选框退场**（复选框只留在表单多选场景）；
- **互斥多选一**（如压缩策略三档）用下拉——竖排 radio 在右列放不下长标签；
- **保存行**：显式保存分区的按钮行放行卡列表之下左对齐，「已保存」与错误条随行；
  就地生效分区（外观 / 语言）无按钮（§四 保存模型）；
- **宽内容例外**：工作区目录列表、暴露快照面板等天然满宽的块不硬塞行式，按块呈现
  （裁定是"绝大部分"，不是全部）。

**两色控件体系（v3.6，用户 2026-10-03 目检裁定：全界面主色只两种——左轨的灰
`--lw-bg-side` 与右栏的白；一切表单控件统一"白底台面"形态，同类特性全局适用）**：

- **底 = `--lw-raised`（亮=白 / 暗=#282828）+ `--lw-shadow-raised` 微弱悬浮阴影，
  无边框**；hover = `--lw-ctl-hover`（亮 #f3f3f3 / 暗 #303030）；适用面 = 文本/数值
  输入、下拉触发器、分段控件、行内动作按钮、保存按钮（`.lw-field` / `.lw-btn`
  两个公共类，style.css 全局层）；**模型（llm）分区暂豁免**（用户 2026-10-03 确认：
  后期单独大改版、**含后端逻辑**——设置页第 1 页目检就此收口）；
- **聚焦高亮框隐藏**（用户裁定）：字段类控件聚焦不出环（`.lw-field:focus{outline:none}`）；
  按钮类仍走全局 `:focus-visible`（点击本就不出环，键盘 Tab 环保留）——§7 规则 12 的
  字段类豁免随此裁定生效；
- **分段控件（新形态 `SettingsSegmented.vue`）**：容器 = 白底台面 + p-1 + 圆角 full；
  选中片 = **`--lw-bg-side`（左轨的灰）** + ink-1，未选 = 透明底 ink-4 hover ink-2；
  `role="radiogroup"` / 片 `role="radio"`；
- **下拉（新形态 `SettingsSelect.vue`）**：触发器 = 白底台面按钮（r-sm，当前值 +
  chevron，`aria-expanded`）；弹出面板 = **白底（raised）+ 1px line + r-md-plus（14）+
  shadow-raised**，teleport 到 body 定位；选项 hover `--lw-wash-2`、**选中
  `--lw-wash-3`（与导航轨/列表选中统一，禁用系统蓝高亮）**；多类别分组时组间 1px
  `--lw-line-subtle` 发丝线 + 11px ink-4 组名；键盘 ↑↓/Home/End/Enter/Esc 全套，
  `role="listbox"` + `aria-activedescendant`；
- **块下说明与行说明一行封顶**（用户裁定）：说明超过一行的精简文案，**说明只占一行**
  ——写入 i18n 时按 亮色 1024 列 / 11.5px ≈ 84 字（CJK） 预算，行说明按左列 ≈ 52 字；
- **快捷键分区（v3.6 升级为可自定义）**：录制式改键（点击键位按钮进入录制态 →
  按组合键 → 归一化为 `Ctrl/Alt/Shift/Meta+主键` 串落 `settings.json shortcut` 即时

  「恢复默认」按钮**（回落 `Ctrl+Shift+L`）。

## 五、弹层规则

| 形态 | 判据 | 实例 |
|---|---|---|
| **Modal（收窄）** | 必须**一次说清一个集合**，且不答就不能做别的事（名单 / 数量 / 破坏范围） | 批量卸载二次确认 |
| **Popover**（新增形态） | 非阻断的**局部信息/快选**，锚在触发控件上，点外部即关 | 上下文用量（§3.12）、通知（§3.13）、模型/权限选择、行尾 `…` 菜单、右键菜单 |
| **整页目的地** | 集合类功能：列表 + 筛选 + 批量运营 | 扩展、记忆、定时、设置 |
| **行内展开** | 单条目的详情/编辑，上下文就在列表里 | 记忆条目编辑、压缩详情、工具行明细、**轮次过程组** |
| **默认不弹** | 设置类就地保存、状态变化用徽章/系统消息表达 | 保存成功 flash、state-changed 徽章 |

判据冲突时从严：能行内的不弹 popover，能 popover 的不弹 modal，能徽标的不开新页。
**审批不走 Modal**——它是 §3.17 的内联决策卡；"必须决定"由轮次阻塞保证，不由遮罩保证。

**浮层分级（z-index 阶梯）**——浮层必须挂到壳根（`#locowrk-overlays`）或 body，
否则会被 `isolation: isolate` 的壳困在遮罩之下：

| 层 | z-index | 内容 |
|---|---|---|
| 背景 | 0 | scenic backdrop（预留） |
| 主区列宽柄 | 7 | 转录列两侧的 12px 调宽热区（§2.7）——在 46px 带之下、正文之上 |
| 46px 带 | 10 | 侧栏头 / 会话顶栏 |
| 工作面板 | 20 | 面板列 |
| 面板拖拽柄 | 30 | resize handle |
| 遮罩 + 弹窗 | 40 | modal / 命令面板 |
| 更新提示条 | 45 | banner |
| toast 栈 | 50 | 浮起通知 |
| 菜单 / popover | 60 | 右键菜单、通知、用量、模型选择 |
| 窗口控制 | 1000 | 恒在最上 |

**Popover 形态**：圆角 14px、`--lw-bg-elevated`、`1px var(--lw-line-subtle)`、
`--lw-shadow-dialog`、`backdrop-filter: blur(12px)`；入场 = 淡入 + `scale(.96)` 200ms。
popover 允许边框（浮层语法），平面内组件不允许（§6.1）。

## 六、design tokens / 主题 / 排版 / 动效

> 原型 `docs/design/ui-prototype/css/tokens.css` 是本节的**可执行版本**，数值以它为准。

### 6.1 色：中性阶 + 语义层，平面内用「叠透明」分层

- **唯一颜色源 = 13 档中性灰阶**（`--lw-gray-0/50/75/100/300/500/550/600/700/750/800/900/1000`
  = `#ffffff / #f9f9f9 / #f3f3f3 / #ededed / #afafaf / #5d5d5d / #4f4f4f / #414141 /
  #303030 / #282828 / #212121 / #181818 / #0d0d0d`）。
- **没有品牌彩色强调色**：`--lw-accent` 暗色 = 白 `#ffffff`、亮色 = 近黑 `#1a1c1f`。
  彩度只出现在**状态**：ok / warn / danger / info / purple（+ 扩展市场的橙色标签 tint）。
- **表面层级**（暗色缺省值，亮色在 `:root[data-theme="light"]` 覆盖）：

| token | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| `--lw-bg` | `#181818` | `#ffffff` | 主页面底 |
| `--lw-bg-side` | `#000000` | `#f3f3f3` | 侧栏 / 设置导航轨（**向"更极端"方向偏离主区一档**） |
| `--lw-bg-dock` | `#212121` | `#fafafa` | 工作面板列 |
| `--lw-bg-inset` | `#0d0d0d` | `#ededed` | 代码块 / mono 井 |
| `--lw-bg-secondary` | `#212121` | `#f9f9f9` | 次级平面 |
| `--lw-bg-tertiary` | `#282828` | `#f3f3f3` | 三级平面 |
| `--lw-bg-elevated` | `#212121f5` | `rgb(255 255 255/.70)` | 浮层实底 |
| `--lw-bg-composer` | `#212121f5` | `#ffffff` | composer 卡底 |
| `--lw-raised` | `#282828` | `#ffffff` | 控件"抬起"底（分段控件选中、字段聚焦） |

**平面内分层铁则（抄参考对象的核心技法）**：同一平面内的结构**靠半透明 tonal wash 表达，
不用边框**——`--lw-wash-1`（叠 3.5%，卡片/行底）、`--lw-wash-2`（6%，hover/字段井）、
`--lw-wash-3`（8%，选中/更深）。**1px 边框只留给浮层**（菜单/弹窗/popover）与
`--lw-elevation` 发丝环——边框是"层高"的提示，不是分隔工具。文档与代码里出现的
"平面内 1px 分隔线"一律视为待清除的技术债。

- **文本**：`--lw-ink-1`（最亮）/`-2`（次级 70%）/`-3`（三级 52%）/`-4`（弱 38%）/
  `-5`（占位 20%）。暗色 = 白叠 alpha，亮色 = 近黑叠 alpha / 实色（见 tokens.css）。
  **alpha 而非实 hex** 是刻意的：hover 与浮层底变化时每级保持一致。
- **状态色**：ok `#40c977` / warn `#ff8549` / danger `#ff6764` / info `#afafaf` /
  purple `#c27aff`（亮色：`#00a240` / `#e25507` / `#e02e2a` / `#5d5d5d` / `#7c3aed`）。
- **阴影**：只给浮起件。`--lw-shadow-dialog`（弹窗）/`--lw-shadow-composer`
  （composer，`0 3px 7.5px #0000000a, 0 0 20px #0000000d`）/`--lw-shadow-raised`
  （控件抬起）。**平面内组件不得有阴影**（v3.6 唯一例外：表单控件"白底台面" =
  raised 底 + shadow-raised，§3.32·七；`--lw-ctl-hover` 为其 hover 档 token）。
- **遮罩**：`--lw-scrim` 暗色 `rgb(0 0 0/.45)`、亮色 `rgb(26 28 31/.28)`。

**已知偏差（如实记录，待裁定）**：亮色 `--lw-ink-4`（`#afafaf`）在白/`#f3f3f3` 上对比度
仅 2.2:1 / 1.98:1，**低于 WCAG AA**。这是参考对象的原值。**暂行规则：亮色下 11–12.5px
的文本一律不得使用 ink-4，最低用 ink-3；ink-4 降级为非文本用途（图标、装饰、占位图形）。**
是否直接改亮色 ink-4 取值留待用户裁定。

### 6.6 动效系统（v3.2 重写，本节是动效的唯一权威）

**一、动效 token（两主题共用，`tokens.css` 必须齐全）**

时长四档：

- `--dur-instant: 90ms` —— 按压反馈（`:active` 缩放）
- `--dur-fast: 150ms` —— 状态色变、**一切退场**
- `--dur-base: 200ms` —— 入场、展开、滑动指示器、进度
- `--dur-slow: 300ms` —— 一次性强调、跳回最新

缓动四条：

- `--ease-out: cubic-bezier(.22, 1, .36, 1)` —— **入场 / 展开**（起步快、尾巴极缓）
- `--ease-in: cubic-bezier(.4, 0, 1, 1)` —— **退场 / 收起**（起步缓、尾巴快）
- `--ease-standard: cubic-bezier(.2, 0, 0, 1)` —— 颜色 / 状态 / 微调（两端都有缓冲）
- `--ease-slide: cubic-bezier(.32, .72, 0, 1)` —— **滑动类专用**（胶囊指示器、抽屉、
  折叠高度）：前段快、尾部极缓，读起来是"滑到位并停住"
- **命名是权威的**：`--dur-instant|fast|base|slow` 与 `--ease-out|in|standard|slide` 这八个名字为准；
  原型 `tokens.css` 里的旧名 `--motion-fast|normal|slow` 是历史残留，落地时统一改名。

**明确禁止过冲 / 回弹 / 弹跳（overshoot / spring / bounce）**——这是有意画的边界：密集 UI 里
过冲会让相邻元素互相干扰，也会让人怀疑"是不是又动了一下"。要"缓冲感"靠 `--ease-slide` 的长尾，
**不靠过冲**。（日后确实想要，先改本条再实现。）

**二、动效类别（封闭清单；新动效先在此扩表，不许在组件里即兴写）**

**① 状态色变** —— `--dur-fast` + `--ease-standard`：hover / focus / disabled 的底色与字色。
这是**唯一**允许在 `@layer base` 写全局 transition 的一类（组件不再散写）。

**② 入场** —— `--dur-base` + `--ease-out`：

- 浮层（弹窗 / popover / 菜单 / 命令面板）：`opacity 0→1` + `scale(.96)→1`；菜单类再加
  `translateY(-4px)→0`；
- **遮罩比内容先到**：遮罩只做 `opacity`，用 `--dur-fast`（否则会出现"内容先亮起来、
  背景后变暗"的错序）；
- 系统记录条：`opacity` + `translateY(-6px)→0`；toast：`opacity` + `translateX(8px)→0`；
- 列表项插入：`opacity` + `translateY(-4px)→0`；
- 抽屉（侧栏 / 工作面板）：`translateX(±12px)→0` + `opacity`。

**③ 退场** —— `--dur-fast` + `--ease-in`，**比入场快一档且用加速曲线**：退场是"我知道了"，
拖它就是拖用户。浮层退场 = 入场反向且**距离减半**（`scale(1)→.98`），不做对称的"慢慢缩回去"。

**④ 展开 / 收起（滑动 + 缓冲，本次新增）**：

- **高度驱动**：外层 `display: grid; grid-template-rows: 0fr → 1fr`、内层
  `min-height: 0; overflow: hidden`；或由 JS 量出的 `scrollHeight` 驱动 `height`。
  **禁止 `max-height: 9999px` 这类写法**——它让时长变成随机值（行越多越慢）；
- **展开**：高度 `--dur-base` + `--ease-slide`；内容 `opacity 0→1` **延后 40ms**——
  高度先起、内容后显，视觉上是"滑出来"而不是"撑开"；
- **收起**：高度 `--dur-fast` + `--ease-in`；`opacity 1→0` **不延后**（内容先淡、空间随后收）；
- **嵌套折叠**：一次操作**只动被操作的那一层**，其内部子单元 `transition: none`——
  否则一次收两层会变成"果冻"；
- **动画结束后移除 `overflow: hidden`**（否则聚焦环、阴影、绝对定位的浮层会被裁掉）；
- 动画期间不抢焦点；键盘触发的展开，**动画完成后**把焦点移入展开体第一项。

**⑤ 滑动指示器（胶囊 / 分段控件 / 页签，本次新增）**：

- 活动指示器 = 绝对定位的圆角块，**只动 `transform: translateX()` 与 `width`**——不动
  `left`（那会触发重排），不动 `background`（那是突变）；
- 时长 `--dur-base`、缓动 `--ease-slide`；
- **首次挂载不播**（指示器直接落在正确位置），只在"选中项变化"时播；
- **连按不排队**：`transform` 天然从当前计算值继续，快速连按表现为"追着停下"，
  不需要特殊处理；
- 指示器需要跨行时（页签条换行）**不播、直接跳**——滑过第二行会穿过文字。

**⑥ 进度与数值** —— `--dur-base` + `--ease-standard`：进度条宽度、用量环弧长。
**数字本身不插值**（跳字比滚动数字更好读）。

**⑦ 一次性强调（只播一次，禁止循环）** —— `--dur-slow` + `--ease-out`：**只用于需要用户决策
的元素**（审批卡入场时染底从该风险档的 10% 落到 7%）。这是把视线拉过去的唯一手段——
不闪、不响、不弹。

**⑧ 运行指示点**（保留原例外条款）—— 4px 脉动点，`opacity .35 ↔ 1`，1s 无限：
**唯一允许的常驻动画**。理由：它是"还在跑"的唯一信号，且只在真的有任务在跑时存在。

**三、显式禁止**

视差 · 回弹 / 过冲 · **整页横滑**（桌面没有返回手势，横滑会暗示"可以滑动"，是假承诺）·
hover 位移（列表里会造成抖动，只允许变色）· chevron 旋转（只换字形）· 逐字打字机 ·
骨架以外的装饰动画 · **全局 `transition: all`**（会与 hover 过渡互相打架，还会掩盖漏写的过渡）·
主题切换时给 `*` 挂全局过渡（同样打架；主题切换只让根容器的底色与文字过渡一次 `--dur-base`）。

**四、焦点与滚动**

焦点环**不做过渡**（延迟会让人以为没聚焦）；滚动一律跟手（`scroll-behavior: auto`），
只有"跳回最新"用一次 `--dur-slow` 平滑。

**五、无障碍（reduced motion）**

`prefers-reduced-motion: reduce` 时：所有 `transition-duration` / `animation-duration` 归
`0.01ms`，`scroll-behavior: auto`；**脉动点与一次性强调整块不显示**（`animation: none`）——
而不是"变成 0.01ms 的无限闪烁"（那反而更刺眼）。

### 6.7 焦点环与滚动条

- **焦点环**：`:focus-visible { outline: 1.5px solid color-mix(in oklab, var(--lw-focus) 80%,
  transparent); outline-offset: 2px }`；字段类控件（填色会变）改用软环
  `box-shadow: 0 0 0 2px color-mix(accent 22%, transparent)`。
- **滚动条**：10px，拇指**静止时透明**；仅当所属区域 hover / 含焦点 / 带
  `data-scrolling="true"`（滚动中短暂置位）时显形，
  `color-mix(in oklab, var(--lw-ink-1) 16%, transparent)` + `background-clip: content-box`
  + 3px 透明边框；拇指自身 hover → 28%。滚动容器一律 `scrollbar-gutter: stable`
  （**副作用：正文列会比 composer 列左偏约 5px，属预期，不做魔法补偿**）。

## 七、扩展规则（功能性批次照做）

1. **新数据** → 新 store 或既有 store 加字段；事件进 §4.1 表、命令进 §4.2 表。
2. **新页面** → 先过 §2.4 判据（是否值得成为目的地；不是就进设置或行内）；集合类一律
   §3.1 列表页模式起手。
3. **新交互** → 先过 §五弹层规则（能行内的不 popover，能 popover 的不 modal）；
   新徽章 → 进 §3.4 对应族。
4. **settings.json 新分区** → §3.2 表加行，占位同批替换。
5. **改壳骨架（§二）或模式组件本身** → 视为规则变更，**先改本文件再动码**。
6. **新颜色** → 平面内只许 §6.1 的表面/wash/ink/line 角色 token；状态色只许 §3.4 五族
   的语义角色类（`text-ok` / `bg-danger/16` 等）。**组件层禁止出现 Tailwind 的
   `neutral-*` 与任意 `hue-shade` 类**——§6.1 的 38 阶 hue 重映射表随本次改造**收缩到
   语义色**。原型里新增的橙色标签 tint 走 `--lw-warn`。
7. **新动效** → 只许 §6.6 的清单；新入场形态先改 §6.6 再实现。
8. **原生系统对话框**（目录 / 文件选择）统一由 Rust command 封装（`pick_directory`），
   tauri-plugin-dialog 仅 Rust 侧调用，前端零新增插件依赖。
9. **新增 theme token 必须两形齐给**（hex + rgb 三元组，§6.2），并同步亮色块。
10. **视觉与交互先在 `docs/design/ui-prototype/` 迭代**，定稿后再落 Vue；原型不得引入
    构建步骤或外部依赖。
11. **文案一律走 i18n**（`t()`）：zh / en 同批加键；**工具名与动作名也走 i18n**——§3.18 的
    映射是 i18n key，不是硬编码中文。会话内容不是文案（§3.3 纪律照旧）。
    **i18n 文案里的 vue-i18n 保留字符必须转义**：`@`（linked 语法）、`|`（复数分隔）、
    `{}`（插值）写成 `{'@'}` / `{'|'}` / `{'{'}`——裸写会编译崩或被吞（㉕ 白屏、㉕·fix
    shellHint 被竖线劈成复数只显示"log"，两例同源）。
12. **无障碍基线**：图标按钮必有 `aria-label`；可折叠项必有 `aria-expanded`；modal 用
    `role="dialog"` + `aria-modal`、菜单用 `role="menu"`、决策卡用 `role="region"`；
    `Esc` 关浮层栈顶；焦点环恒可见（`:focus-visible`，§6.7；**v3.6 用户裁定豁免：
    字段类控件（文本/数值输入与下拉触发）聚焦不出环**，按钮/行类键盘环照旧）；
    **不许用纯颜色传达状态**（状态点必须配文案或 `aria-label`）。
13. **不许新增受控字面量**：字号 / 字重 / 行高 / 字距 / 圆角只能取 §6.5 / §6.3 的阶梯；
    颜色只能取 §6.1 的角色 token；间距只能取 §6.4 的档位；控件尺寸只能取 §6.4 的三个常量。
14. **本文与原型的关系**：原型是抽样演示，**规范以本文件为准**——原型没做到、做不细的形态，
    只要写在本文里就是必须实现的（用户 2026-10-01 裁定）。
