## 零、铁律（判错依据，无例外）

0. **自发明一律判错**：任何界面元素必须落在 §二 类别清单的某类的唯一形态上。清单外的新形态 = 判错，除非先修订本标准再写码（文档先行）。
1. **不得硬编码**：颜色 / 圆角 / 阴影 / 动效时长一律 `var(--lw-*)`；字号 / 间距用 §五 令牌（建齐前由门禁二级报告）。
2. **不得同类多套**：同一类别的第二套实现 = 判错（先例教训：同为下拉，DefaultModelMenu 量实际宽而 SettingsSelect 按预估宽定位 → 裁切缺陷只修了一处）。
3. **文案不是文章**：设置说明一行封顶（§四）。
4. **门禁判错不可绕过**：pre-commit 双闸——stylelint（CSS 声明维度，`desktop/stylelint.config.cjs`）+ `scripts/check-style.mjs`（模板维度）——一级判错提交即被拒；豁免必须登记在 §七。
5. **特例申请制**（用户 2026-10-06 裁定）：个别特殊点缀/特殊形态需要偏离唯一形态时，**先申请后执行**——申请须写明：①形态描述 ②出现位置 ③为什么唯一形态不适合 ④影响范围；用户批准后**先修订本标准**（登记 §七 豁免或新增类目）再写码。豁免凭证 = 行内 `/* stylelint-disable-line <规则> -- 豁免§七:<批准条目> */`（模板维度用 `/* lw-waive: <批准条目> */`），无凭证豁免按判错处理。

### ① 动效矩阵（用户 2026-10-06 裁定）

| 类别 | 进场 | 收尾 | 退场 |
|---|---|---|---|
| 侧滑面板（右栏/侧栏抽屉） | 滑动 200ms | **弹簧回弹** `--ease-spring`（待建） | 150ms 快速收回，不回弹 |
| 折叠面板（过程组/记忆树章节） | 滑展开 200ms | **缓冲** `--ease-out` | 150ms `--ease-in` |
| 弹出面板（一切浮层） | 滑动弹出 200ms | **缓冲** `--ease-out`（暂定·勾①，候选弹簧） | 150ms `--ease-in`，**禁止无退场** |
| 模态 | 遮罩 150ms 淡入 + 面板 200ms 缩放缓冲 | 同左 | 反向 |
| toast | 滑入 200ms | 缓冲 | 150ms 滑出（必须存在） |
| 状态过渡（hover/选中/底色） | 150ms `--ease-standard` | — | — |
| 进度条 | 200ms width | — | — |
| 常驻脉动点 | 1s 循环（唯一常驻动画） | — | — |

- **禁止发明矩阵之外的第五种动效**；**禁止无动效硬切、禁止无退场**（现状缺口：设置下拉、审批 scope 上弹、模型缺省菜单 3 处硬切；用量/通知浮层、行尾菜单、toast 4 处无退场——收敛批补齐）。
- **常驻循环动画白名单**（全站仅此三件，新常驻循环 = 走特例申请制）：运行脉动点 `lw-pulse 1s` · 不定进度条 `lw-indeterminate 720ms alternate` · 欢迎页吉祥物 `welcome-float/blink 4s`（插画，§七）。
- reduced-motion 全局归零保持（盘点确认现状无缺口，不得新增例外）。
- **位置与遮罩（用户 2026-10-06 补充裁定）**：①**toast = 顶部固定 64px 水平居中（中上位；chrome 带 46px 下方）**——不用 vh（窗口越高百分比越下沉，中上感全失，多轮目检教训）；入场 = 上方 -8px 滑入 + 缓冲（lw-pop-down 同语言），退场 = 收回淡出 150ms，停顿统一 4s（hover 暂停），宽度统一 `min(260px, 100vw−32px)`（用户裁定值 260；目检链 420→360→320→260）；现右下角形态退役。②**⌘K 搜索面板 = 水平居中、顶缘 14vh 弹出**（面板最高 60vh ⇒ 视觉重心 ≈44vh = 居中偏上；v2.78 目检修正：只给 items-start 丢了 justify-center 会贴左，面板重心须按「顶缘 + 半高」推算不能只看顶缘）。③**大面板（模型服务编辑等编辑型模态）= 屏幕居中模态**。④**模态族全部统一加遮罩层**（`--lw-scrim`）——不加遮罩时弹窗与主面板同色分不清边界（用户原话）。

### ② 设置说明文案（用户 2026-10-06 裁定）

- **一行封顶（≤32 汉字）**，白话，只说「这是什么 / 改动影响什么」；工程原理、括号解释、第二句一律不进界面（细节进 tooltip 或文档）。
- 现状违规 51 条（≥30 字，最长 84 字），压缩为收敛批工作项（勾② 裁定执行方式）。

### ③ 弹出面板（9 处浮层收敛为 1 种；用户 10-05/06 裁定）

- 形态：`--lw-bg-elevated` 不透明底 + **1px `--lw-line` 外围发丝线围边** + **微弱悬浮影** `--lw-shadow-pop` + 圆角 **14**（暂定·勾③）。
- **模态面板圆角 = `--lw-r-lg-plus`（18）**（v2.1 补钉：ConfirmDialog 与 ProviderSetupDialog 原本 18/16 各一套，判同类多套；模态归此值，遮罩 `--lw-scrim` + `lw-modal` 过渡同为其唯一形态）。
- 结构：组与组之间 = **两头不到端的发丝线分割**（`--lw-line-subtle`，两端缩进 12px）。
- 对齐三则：**靠左出的面板与触发钮左对齐；居中弹出居中对齐；靠右出的右对齐**。
- **视口钳制义务**：渲染后必须量**实际尺寸**（不得用预估宽）——右对齐触发器右缘、四边钳 8px、底部放不下向上翻（实抓教训：SettingsSelect 预估宽定位致裁切）。
- 收口：**一律 Esc + 外点自持**，并且**一次 Esc 只许有一个消费者 = 开着的那层吃掉它**
  （2026-10-18 台账 T10 按当时给的 **(a)** 路线裁定；**(b)**「把缺 Esc 的三处登记进 §七」作废——
  那三处按 Esc 不关若成为定面，就是标准自己欠的债被洗成特例）。
  - 优先级只许一个出处：`lib/use-popover.ts` 的 `anyLayerOpen()` + 内部 `useLayerPriority`。
    浮层经 `useDismissOnEsc(close, open?)` / `useDismissOnOutside(root, open)` 收口时**自动**占位与
    归还：省略 `open` = 由父 `v-if` 渲染、挂载即打开（`chat/ModelSelector.vue`、
    `shell/NotificationPopover.vue`、`settings/model/DefaultModelMenu.vue` 那一族）；有本地开关的
    必须传（`shell/SubagentsMenu.vue` 常驻顶栏、`chat/PermissionCard.vue` 的 scope 下拉）——
    不传的后果是常驻组件长期占位，输入框那条 Esc 链（停止 / 拒审批）整条哑掉。
    占位与归还都由注册面自己管，站点没有"忘记归还"这个可犯的错误（卸载无条件归还）。
  - 输入框那条链（`Composer.vue`：斜杠面板 → **让位给开着的浮层** → 跳过 ask → 拒绝审批 →
    停止 → 交出焦点）改问 `anyLayerOpen()`，不再点名认识某一个浮层。改前它只认识 `showModels`
    一个，于是每给别的浮层补 Esc 就多一个双动作，而双动作的另一半是**不可逆**的（拒审批）——
    这正是当时判定"直接补比不补更糟"的那条。
  - 实测（2026-10-18 · T10 收尾）：外点站点 **6** 处全部带 Esc，缺 Esc 的三处已补齐
    （现查 `grep -rlE 'document\.addEventListener\("pointerdown"|useDismissOnOutside\(' desktop/src/components`）；
    `chat/ModelSelector.vue` 自写的那份 document keydown 换成共享件 ⇒ 同一判定的第二个出处消失。
    机械闸 = `scripts/check-single-source.mjs` 的 **SS9**（外点与 Esc 成对在场）/ **SS9b**
    （让位判定还在）/ **SS9c**（计数器只许一个出处），`make selftest` 为这三档各留一条窄变异、
    末行 `SELFTEST_ALL_CAUGHT`（总档数每刀都会漂，唯一出处 = 闸自己的输出行，标准里不钉）；
    行为面 = `desktop/tests/popover-esc.spec.ts` **9 条**（四发变异各打中一条，含"卸载不归还"
    与"把计数写成布尔"两种缺陷形状）。
  - 沿用原裁定、不动的两半：「关掉谁」三种写法并存见 §七；外点事件名 `mousedown`→`pointerdown`
    已归一（实测残留 0）。
- 验收矩阵**必含贴边位**：触发器贴窗口右缘/下缘时不得裁切（每浮层必测）。

| 底 / 圆角 / 纵向内边距 | **都没有**。展开体外壳一律无底、无圆角；纵向间距由父级 flex gap（`--lw-gap-8`）给 |

**井 ≠ 展开体（底色归属）**：`--lw-bg-inset` 只给**内容井**（代码块、终端块、diff 卡这类自带材质的内容体），**展开体外壳本身不带底**。旧状（思考行一个灰底圆角框、工具行裸排）判错。

**展开体属性行唯一口径**：标签列取 **行级** `max-content` + `column-gap: var(--lw-gap-8)`；**值列不跨行对齐是明知的代价**——「值列对齐」必然把短标签撑出大段空（`sessions` 被 `total_sessions` 撑约 50px），两版实测都被用户驳回；取「间距恒定 8px」。

**落点唯一（红线，要机器判据钉住）**：`.prow__*` 的布局只许出现在 `ProcessRow.vue`；`.tdetail__*` 的布局只许出现在 `ToolDetailView.vue`；两个组件以上的共用外壳只许出现在 `style.css` 的 `.lw-expand`。任何组件自己复制行骨/外壳几何 = 判错。

**状态位唯一**：成功态**什么都不出**（无对勾、无时长）；失败态是整屏唯一 danger；状态词唯一落点 = i18n 的 `tool.state.*`（组件里不许写第二套词）。

| 状态 | 词（zh / en） | 今日可渲染？ |
|---|---|---|
| 等待中 | `state.waiting` ＝ 等待审批 / Awaiting approval | ✅ 工具行 |
| 执行中 | `state.running` ＝ 执行中… / Running… | ✅ 工具行、子代理行、L1 行 |
| 已执行 | — | ❌ 成功态刻意不出声，不留词 |
| 执行失败 | `state.failed` ＝ 执行失败 / Failed | ✅ 工具行、子代理行、展开体错误块 |
| 已拒绝 | — | ❌ 拒绝后那一步不落行（`decision` 行全隐藏，v2.98），无数据 |
| 已停止 | `turn.stopped` ＝ 已停止 / Stopped | ✅ **轮级**标记（`TurnTimerLine` 的 `stopped`），只标最新一轮，不逐行重复 |
| （G2）结果未知 | `state.unknown` ＝ 结果未知 / Outcome unknown | ✅ 只在崩溃恢复的悬空行 |

词是**步骤级**的；`turn.*`（工作中 / 已工作 / 已停止 / `{n} 个问题`）是**轮级**的，两族不许互相借。**思考行收起态是刻意两分**（实时轮给时长 `思考 · 12 秒`、重放轮给首句摘要）——落盘投影不带时戳，别当 bug 修（AF-05）。

**一轮只有一个头行**（AF-14 终版，用户 2026-10-19 三次裁定收敛：先否「并成一行」`已完成 · 已工作 0 分 6 秒`、再否「拆散时长那层」）：`TurnTimerLine` 就是那个头行——`✓ 已工作 N 分 N 秒` 读数（`TurnTimerReadout`，含走表）＋ 轮级标记（`stopped` / `problems`）。**动作块组头整层已删**：`TurnProcess.vue` 只剩组体（块根 `turn` + 8px 行距），三件事随之各归其位：①读数只有一份，不许组头再写一遍（旧状组头 `34s` 与容器行 `0 分 34 秒` 是两个数各算各的）；②「已停止」「N 个问题」下沉到轮头；③「· N 个工具」不再渲染（轮内动作行自己看得见有几件工具）。整行可点 = 折叠 / 展开整个轮容器。

**本类明确不授权**：新令牌以外的尺寸自造（行骨几何两处 `calc(14px / 2)` 是「光学修正」不是间距档）、第二套展开壳、按工具逐个写死的截断宽度（AF-15 收成一处）、再引入任何形态的「组头 / 块头」行（AF-06 随该层删除而结案）。

### ⑱ 右栏产物页签（文件 / 图片；用户 2026-10-18 裁定「点进去就地看」）

工作面板的页签**只有一套壳**（`WorkPanel.vue`：28px 药丸、常态 wash-1 / 选中 wash-3、可关闭、`max-width 200`）——本类新增的只是**内容面**，不是第二套页签：

| 页签 | 何时开 | 内容面 |
| --- | --- | --- |
| 文件（`kind: "file"`） | 点工具行文件名 / 展开体代码块头 / diff 行号；`.html` 除外 | `.md` 走既有 `renderMarkdown`；其余文本走 shiki + **行号列**（与 diff 卡同口径等宽）；截断 / 二进制 / 读不到都出**一行说明**，不出空白 |
| 图片（`kind: "image"`） | 点工具行缩略图 / 消息里的图 | 自适应宽度的图 + 「全屏查看」入口（复用既有 `ImageViewer` 浮层） |
| 浏览器（`kind: "browser"`） | `.html` / 手动输入 | 既有形态不动（挂 `lwpreview`） |

- **判定唯一落点** = `desktop/src/lib/artifact-routing.ts` 的 `routeArtifact(path)`；任何组件自己 `if (ext === …)` = 判错。
- 页签身份：**同 `filePath` 只开一签**（再点 = 激活 + 滚到那一行）；同图以 `assetId` 为准。
- **只读**：文件与图片页签不给编辑面（改文件仍走工具，specs/08 非目标）。
- 井口径：文件页签的代码体、图片页签的画布走 `--lw-bg-inset`；文件头行沿用 `ReviewTab.vue` 的 `wash-1 + r-md + 12/14` 内边距——同族不许两种头行。
- 本类不授权：图片标注 / 裁剪（只读 + 另存为之外不处理）、文件树 / 全局搜索 / 页内查找、预览↔源码切换钮族。

1. **机械门禁** `scripts/check-style.mjs`：
   - `--staged`（pre-commit 挂载）：暂存 .vue 一级判错 = 提交被拒。一级 = 裸 hex 色、裸 rgb 字面色、裸 px 圆角、tailwind 内建圆角类（rounded-sm..3xl / rounded-[..px]）、裸动效时长、裸 box-shadow——这些维度令牌已齐，没有借口。

2. **验收矩阵**（每批目检 + 走查）：每类至少测 默认/hover/选中/禁用 × 明暗 五态；浮层加测贴边位（右缘/下缘）；**同类不同样 = 判不通过**。§二⑯ 另带四条画布专属增项（双主题网格可见性 / 拖拽无过渡残影 / 缩放两极端连线端点 / 键盘全路径 + 450px 地板可达）。
3. **文档先行**：需要清单外形态 = 先修订本标准（说明为什么清单不够用），再写码。
4. **门禁实测边界（v2.2 用两份探针夹具实测得出；夹具曾住 `tmp/q13-probe/Probe*.vue`，属一次性件、不入库，已随台账 T8 清理作废——实测结论以本条正文为准，规范语义未变）**——下列两面**闸管不到，只有本标准正文承重**，写新形态时不许假设"门禁会替我拦"：
   - **整值子串匹配**：`declaration-property-value-allowed-list` 的配置正正则无锚（`/var\(--lw-/i`），实测一条声明只要**任意一段**含 `var(--lw-` 即整条放行 ⇒ `transition: transform 0s, background-color var(--dur-fast) var(--ease-standard)` 这种夹带裸时长的多段写法能过闸（§二⑯ 已明令禁止）；`transition-duration: 0s` 单写**判错**，合法写法是 `transition: none`。同一机制下 `background-image: radial-gradient(color-mix(in oklab, var(--lw-ink-1) 14%, transparent) 1px, transparent 1px)`（原型现写的网格档）实测**也放行**——注意 `box-shadow` 那条配置是**专门为 `color-mix(in oklab, var(--lw-` 写了一个分支**才允许就地混色的，`background-image` 这边没有这种授权，它只是被子串放过 ⇒ §二⑯ 按上位 §3.3「禁临时透明度拼接」判错。
   - **完全不在射程的属性**：`background-size` / `background-position` / `background-repeat` / `stroke-width` / `fill`（`none` 与 `var(--lw-` 之外仍受色档管）/ `cursor` / `will-change` / `image-rendering` / `overflow` / `z-index` / 任意 `width`·`height` 的裸 px——实测全部放行。§二⑯ 对其中每一项钉了唯一值，这就是那一刀的实际产出。
   - **反向确认夹具是活的**：同一份探针里各放一条已知必红的裸值（`padding: 10px 12px`、`font-size: 13px`、`border-radius: 14px`、`transition: transform 240ms ease-out`），四条全被报出 ⇒ "通过"不是扫描瞎（同族纪律 = 零命中要配正对照，这里是放行要配正对照）。
   - 扩闸（逐段校验 transition、给 background 族加档）需要自定义 stylelint 规则，**不在 Q13 范围**，登记为 Q14 之后的可选项；在那之前本节这一条是唯一防线。
5. **样式落点闸** `scripts/check-css-ownership.mjs`（2026-10-18 建，接进 `sh scripts/tasks.sh gates` 与 `selftest`）：把 §二⑰ 那条「落点唯一」红线变成机器判据——`.prow__*` / `.tdetail__*` / `.tool__*` 的**定义**（`.vue` 的 `<style>` 块或 `.css` 里的选择器）只许出现在各自归属组件；跨组件公共面 `desktop/src/style.css` 对这三族也算合法落点（它管选择策略、滚动这类全局事，不是行骨几何）。`.lw-expand` 只许定义在 `style.css`，且必须有组件在用（0 = 死代码）。别的文件**用**这些类名不算错，注释里提到也不算（先剥注释）。读数 `PREFIXES=4 VIOLATIONS=0 USES=N`；`--map` 打印实测归属表；`--selftest` 六项变异自证（复制行骨 / 抢外壳定义 / 外壳没人用 / 各归其位放行 / 行骨进全局表放行 / 注释不算）。
