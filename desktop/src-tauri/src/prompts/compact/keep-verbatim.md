# 逐字保留（二）：可查证的符号与串

这一套管的是**指得准**——下一个自己要能照着这些串去找东西，模糊化就没法查了。

- 精确保留：文件路径、符号名、命令、错误串、URL、标识符。照原文写，不要翻译、
  不要简写、不要改大小写。
- 用短引用代替长复述：能从上面「相关文件」里的文件读回来的东西，不必在摘要里
  重抄一遍正文。
- 每节写紧凑：单行要点，不要散文段落、不要嵌套列表。
- 带上**有后果的**流程状态：改动是未提交 / 已提交 / 已推送 / 在评审 / 已合并。
- 只把还没答案的用户问题或请求写进「下一步」；已经被后续历史解决掉的，不要重复列。
- 不要提"正在压缩上下文"这件事本身，也不要复述压缩过程。
