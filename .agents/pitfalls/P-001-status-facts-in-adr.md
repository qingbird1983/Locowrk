# P-001：ADR 里写了“当前状态”，改名后无法修改

- 首次记录：2026-10-28（目录迁移为 Locowrk 时发现）

## 现象

目录改名后，`docs/adr/ADR-0007-license-and-identity.md` 的“后果”一节仍写着“仓库目录当前仍是 `pi-go-desktop`”。这句话已经为假，但 ADR 只增不改，不能顺手改；只翻 ADR 的读者会拿到过期事实。

## 根因

把**某时刻的状态**（目录名、版本号、进度、谁还没确认）写进了**不可修改的决策记录**。决策可以长期不变，状态几乎每轮都变，两者生命周期不匹配。

## 修复

- ADR 原文保留（当作历史记录），现状写进 `.agents/CONTEXT.md`、路线图看板与 `CHANGELOG.md`。
- 本轮已把 CONTEXT、看板、Phase 0 报告、Phase 1 备注里的过期状态改完。

## 预防（怎么不再犯）

- 写 ADR 时只写：背景、决策、理由、备选、后果中的**结构性**内容（“需要一次命名迁移”），不写“当前叫 X”“目前在第 N 阶段”。
- 自检问题：这句话一年后会不会自动变成假话？会 → 移到 CONTEXT/看板/CHANGELOG。
- 发现 ADR 有假句时：不改 ADR，改活性文档并在 CONTEXT 关键提醒里点出该句为历史。

## 失效条件

若将来 `docs/standards/03-documentation.md` 建立 ADR 勘误机制（允许追加勘误节），本条可改写为该机制的说明。
